AI & I by Every：Notion’s Founder on the One Thing Your AI Is Missing

一句话结论： AI 让每个人都能制造软件，但真正持久的产品价值会从固定的 UI 和流程，转向企业自己的数据、上下文与语义。

Notion 创始人兼 CEO Ivan Zhao 把 vibe coding 放回更长的计算史中：早期计算的愿景是让所有人都能读写软件，而不是把人分成应用制造者和使用者。AI coding agent 让这种愿景第一次变得普遍可行，但“能做出来”只是开始；用户仍需要判断什么值得做、什么应该交给经过打磨的产品来维护。

Zhao 的关键区分是，软件的 UI 和 procedural logic 会快速变化，而数据、上下文和业务语义更持久。Notion 因此更像团队上下文的保管者：让不同 agent 使用这些信息，同时为协作和安全提供边界。他也分享了自己用 vibe coding 制作历史学习游戏的实践，说明 AI 产品的下一步不只是替人完成任务，也可能把学习变成可探索、可对话的空间。
