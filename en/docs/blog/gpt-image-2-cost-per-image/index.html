GPT Image 2 API Pricing: Official Cost per Image, Calculation Method, and Real Bills

API开发2026-05-0811 min readGPT Image 2OpenAI APIImage Generation PricingAPI CostBatch API

截至 2026 年 5 月 8 日，GPT Image 2 API 价格最稳妥的回答要从 OpenAI 官方输出示例开始：1024x1024 图片在 low、medium、high 三个质量档分别是 $0.006、$0.053、$0.211；1024x1536 或 1536x1024 图片在同样质量档分别是 $0.005、$0.041、$0.165。注意，这些是输出示例，不是每一次 API 请求的最终账单。真实账单还可能包含文本输入、图片输入、参考图或编辑图、partial images、重试次数、Batch 路线，或者第三方供应商自己的计费合同。

先看官方每张图示例

中文读者常会同时看到三种价格说法：官方 API token 价格、供应商每次调用报价、ChatGPT 会员使用权。真正做预算时，先把官方输出示例单独放在第一层。

输出尺寸LowMediumHigh这行适合怎么用
1024x1024$0.006$0.053$0.211方图预算的官方起点
1024x1536$0.005$0.041$0.165竖图预算的官方起点
1536x1024$0.005$0.041$0.165横图预算的官方起点

如果你只是想估算"生成一张 1024x1024 high 图大概多少钱"，$0.211 是一个可以落到表格里的输出示例。在采购、报价或产品预算里，先引用这条官方示例，再把编辑、参考图输入、重试、partial outputs 和路线选择分开标注。如果你在产品里要上传参考图、做编辑、让用户多次重试，或者希望异步跑批量任务，这个数字就只能作为起点，不能直接当最终成本。

官方价格行到底在收什么

OpenAI 官方价格页把 GPT Image 2 写成 token 价格行，而不是只写"每张图"。图像相关行包括：image input 每 100 万 tokens $8.00、cached image input 每 100 万 tokens $2.00、image output 每 100 万 tokens $30.00。文本输入也有单独价格：text input 每 100 万 tokens $5.00，cached text input 每 100 万 tokens $1.25。

这些 token 行是官方示例背后的计费基础。普通读者问"每张图多少钱"，需要先看到上面的美元示例；工程团队做成本模型，则必须回到 token 行和请求结构。两层答案都要保留，否则很容易出现两个误判：把 $0.211 当成所有 GPT Image 2 图片的统一价格，或者把供应商的固定调用价当成 OpenAI 官方直连价格。

Batch 是另一层官方价格杠杆。OpenAI 的 Batch 路线适合可以异步等待的任务，价格行更低，例如 image input 每 100 万 tokens $4.00、cached image input 每 100 万 tokens $1.00、image output 每 100 万 tokens $15.00。它不是交互式页面的默认省钱按钮。如果用户点一下就要马上出图，Batch 的延迟和作业语义可能不适合。

真实 API 账单的计算公式

把 GPT Image 2 的单次请求理解成一个小公式，比记一个孤立价格更可靠：

成本组成什么时候出现预算时怎么处理
文本输入每个 prompt 都有文字指令通常不是最大项，但不能写成零
图片输入上传参考图、mask、编辑输入编辑和参考图流程要单独估算
图片输出模型生成的最终图像官方每张图示例主要对应这一项
partial images请求过程中预览或部分输出会增加输出 token 工作量
重试用户重新生成或系统自动补跑每次接受的新输出都要计入
Batch异步任务符合 Batch 条件可以降低官方成本，但牺牲即时性

所以，成本表里最好不要只放"图片数"。更稳的字段是：model、size、quality、是否有图片输入、partial image 数量、重试次数、路线是 direct 还是 Batch，是否经过 provider。这样复盘账单时，团队才能知道钱花在 high quality 上，还是花在参考图、编辑输入或反复重试上。

为什么更大的非方图反而更便宜

官方示例里最容易让人疑惑的是：1024x1536 和 1536x1024 的像素面积比 1024x1024 更大，但同质量档示例价格更低。这个现象不应该被"修正"为像素面积公式，也不应该被写成 OpenAI 页面错误。

预算表应该尊重官方公开的尺寸和质量组合，而不是自己按像素线性外推。假如产品只生成 1024x1024 方图，你可以直接用方图行做第一版估算。假如产品混合横图、竖图、方图和多档质量，就要把尺寸和质量作为两个独立字段保留下来。

这点对电商图、社媒封面和长图海报尤其重要。业务方常会直觉认为"图越大越贵"，但 GPT Image 2 的公开示例告诉你，预算关键不是像素面积，而是官方暴露的尺寸档和质量档。把这个边界写清楚，可以减少上线后因为错误单价引发的预算偏差。

分清 OpenAI 直连、Batch、供应商和 ChatGPT

中文语境里常见的价格混淆，是把四个合同归属放在一张表里比较：

路线价格归属适合谁不能混成什么
OpenAI 直连 APIOpenAI 官方 API 价格要第一方模型身份、官方账单和项目归属的团队供应商固定调用价
OpenAI BatchOpenAI 官方 Batch 价格能接受异步处理的批量任务实时交互出图
供应商或网关供应商自己的合同本地支付、接入路由、统一网关、特定工作流OpenAI 官方直连价格
ChatGPT 计划ChatGPT 消费端权益在 ChatGPT 产品里生成图片gpt-image-2 API 账单

如果你的问题是"OpenAI 官方 API 到底怎么收费"，供应商价格只能作为下一步购买路线，不能放在第一屏当答案。需要比较低价网关时，可以单独研究低价格接入指南。这两个问题要拆开：一个是官方成本计算，一个是供应商选择。

ChatGPT 也一样。ChatGPT 会员可能包含图片生成功能，但那是消费端产品权益，不等于 API 免费，也不会把订阅费自动转换成 gpt-image-2 的 API 账单。API 预算要看模型页、价格页和项目账单，而不是只看 ChatGPT 套餐。

五种工作负载该怎么估算

下面这张表适合作为产品上线前的第一版预算口径：

工作负载第一版估算会改变账单的因素实操规则
草稿测试low 或 medium 官方输出示例多次试 prompt、多次接受输出记录所有被接受的输出，不只记录最终图
正常生产对应尺寸的 medium 示例量级、质量档、偶发重试日志里保留尺寸和质量
高质量交付high 官方输出示例参考图、编辑输入、废稿率high 单独设预算线
编辑密集流程输出示例加图片输入mask、参考图、局部编辑、partial images不要和纯文生图混算
异步批量符合条件时用 Batch 行作业延迟、分批、失败重跑只有能等的任务才走 Batch

供应商路线可能会给出更简单的每次调用价，但那属于供应商合同。它可以有购买价值，尤其在支付、接入和统一路由上；但在解释 GPT Image 2 官方成本时，必须把它放在 OpenAI 直连和 Batch 后面。接入 GPT88 统一网关也是一份独立的供应商合同，实际扣费按官方用量乘以所选分组倍率，具体价格与配额以 gpt88.cc 控制台为准。

上线前做一个小计算器

一个实用的 GPT Image 2 成本计算器不必复杂，但必须保留会改变账单的变量。

字段示例为什么要保留
modelgpt-image-2防止把不同模型价格混在一起
size1024x1024、1024x1536、1536x1024对应官方示例行
qualitylow、medium、high对应质量档示例
has_image_inputtrue / false区分纯生成和编辑/参考图
partial_images0、1、2记录额外输出工作量
retry_count0、1、2记录重试带来的额外输出
routedirect、Batch、provider保留合同归属

有了这些字段，你才能回答真正的运营问题：是 high 质量带来主要成本，还是编辑输入太多？Batch 是否真的适合？某个供应商路线是不是只在特定工作负载下更有意义？如果日志里只有"生成 1000 张图"，这些问题都无法复盘。

还要给团队约定一个口径：对外沟通时说"官方输出示例"，对内复盘时说"完整 API 工作量"。这两个词能减少很多预算误会。前者回答采购或产品经理最先问的单张图数字，后者提醒工程团队把输入、输出、重试和路线都放进同一张账单表里。只要口径清楚，后续比较 direct、Batch 或供应商路线时就不会把不同合同的价格混成一个平均数。

常见问题

GPT Image 2 一张图到底多少钱？

按 2026 年 5 月 8 日的官方输出示例，1024x1024 图片是 low $0.006、medium $0.053、high $0.211；1024x1536 或 1536x1024 是 low $0.005、medium $0.041、high $0.165。真实 API 账单还可能包含文本输入、图片输入、编辑、partial images 和重试。

$0.211 是 GPT Image 2 的固定单价吗？

不是。它只是 1024x1024 high 质量输出示例。低质量和中等质量更便宜，横图和竖图示例不同，编辑和参考图流程也会增加其他计费项。

GPT Image 2 API 有没有官方免费路线？

不要把它当成免费 API 模型预算。是否有特定账户权益，要看 OpenAI 当前模型页、价格页和项目状态。ChatGPT 产品里的图片访问权不是 API 账单。

Batch 一定能让 GPT Image 2 更便宜吗？

Batch 对符合条件的异步任务可以降低官方价格，但它改变的是处理方式。需要实时返回图片的产品，不应该为了便宜把交互式请求硬塞进 Batch。

供应商报价能和 OpenAI 官方价格直接比较吗？

只有先标明归属和计费单位，才有可比性。供应商固定调用价是另一份合同，可能解决支付或接入问题，但不能写成 OpenAI 官方直连价格。GPT88 的接入价格与配额同样以 gpt88.cc 控制台为准。

预算前应该看哪些官方页面？

看 OpenAI API pricing 页面确认 token 行和 Batch 行，看 image generation cost guide 确认每张图示例和公式，看 GPT Image 2 model page 确认 gpt-image-2 的模型身份和 API 路线。
