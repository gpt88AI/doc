# Opentu（开图）到底能做什么？一篇看懂 AI 画布工作台的功能、场景和适合人群

很多人第一次打开 AI 工具，通常只想做一件事：生成一张图片。

但真正开始工作后，事情很快会变复杂：要先整理灵感，再写提示词；生成图片后要裁剪、标注、排版；做产品方案要画流程图和思维导图；视频任务提交后还要追踪进度；结果还得保存、复用和交付。

如果这些步骤分散在聊天窗口、白板、网盘、图片编辑器和任务列表里，创作很容易变成不断切换工具。

Opentu（开图）的思路，是把这些事情放进同一块画布：AI 图片和视频生成、流程图、思维导图、素材库、知识库、任务队列与导出，都围绕一个浏览器工作区展开。

本文结合 [Opentu 工作台](https://agent.gpt88.cc/opentu/) 和 [Opentu 用户手册](https://agent.gpt88.cc/opentu/user-manual/index.html) 当前公开内容，按“功能是什么、适合什么场景、适合谁”做一次完整梳理。

## 一、AI 创作：把想法变成图片、视频和一组素材

### AI 生成图片：适合从 0 到 1 做视觉草稿

在画布底部输入主体、场景、构图和风格，选择当前可用的图片模型，提交任务后到任务队列查看状态。结果可以插入画布、进入素材库、继续编辑或下载。

适合的场景包括商品图、海报、头像、封面、社交媒体配图、概念草图和批量视觉变体。

适合人群：内容创作者、运营人员、设计师、独立开发者、小团队营销人员，以及需要快速验证视觉方向的产品经理。

如果要批量生成，建议先用一个简单提示词和默认尺寸跑通一次，再加入参考图、不同尺寸或批量任务。模型、分辨率、权限和计费以当前工作台为准。

### 灵感创意板：适合不会写提示词或需要快速发散的人

灵感创意板提供模板和预填提示词，让空白画布先有一个可以修改的起点。你可以先选一个方向，再改主体、场景、风格、尺寸和参考图。

它适合做商品展示、封面、头像、社交配图、艺术创作和宫格拆图的第一版尝试。

适合人群：AI 创作新手、需要快速找方向的运营人员、做视觉发散的设计师，以及需要带团队讨论画面方向的人。

模板只是起点。生成后仍要检查画面结构、文字、主体比例和素材使用权。

### 智能拆分图片：适合九宫格和系列内容生产

先生成一张完整画面，再按 2×2、3×3 等网格拆成多个小块，可以用于朋友圈九宫格、系列社媒图片和连续画面。

适合人群：社媒运营、个人创作者、电商和品牌团队，以及需要一次准备一组连续素材的人。

要注意两件事：主体和文字不要刚好落在切割线上；“生成九宫格效果图”不等于已经得到九个独立文件，发布前需要逐块检查和保存。

### AI 生成视频：适合把静态创意变成动态表达

手册覆盖文字转视频、图片转视频以及首尾帧控制等路径。使用前先确认当前模型支持的参考图、时长、画面比例和声音能力，再提交任务并在任务队列追踪进度。

适合的场景包括产品动态展示、短视频内容、广告创意验证、静态图片动效化和分镜预演。

适合人群：短视频创作者、品牌运营、广告内容团队、产品设计师和需要快速验证运动方向的创意人员。

视频生成通常比单张图片更耗时。任务还没有明确结束时，不要重复提交；先记录任务 ID，查看状态和错误，再决定是否重试。

## 二、无限画布：把图片、文字和结构放到一起

### 无限画布与插入内容：适合持续推进，而不是一次性生成

画布可以容纳图片、文字、形状、箭头、思维导图和流程图。手形工具负责移动视野，选择工具负责移动、缩放、复制、删除和多选元素。

适合的场景包括项目白板、方案评审、视觉参考板、活动排版、产品结构梳理和把图片与解释放在一起。

适合人群：视觉创作者、产品经理、教师、研究人员、项目团队，以及需要减少窗口切换的人。

### 画笔、形状和文本：适合快速讲清楚一个想法

画笔可以做手绘、圈重点和快速批注；矩形、椭圆、菱形和箭头可以构建结构；文本工具可以写标题、注释和节点说明。

适合课堂讲解、会议讨论、界面评审、设计批注、流程节点和视觉笔记。

适合人群：教师、顾问、产品和设计团队、远程协作项目组，以及喜欢手绘表达的创作者。

### 思维导图：适合发散、规划和知识整理

你可以从中心主题手动建立分支，也可以让 AI 先扩展结构，再人工调整。已有 Markdown 大纲也能转成思维导图。

适合选题发散、课程大纲、产品需求拆解、项目规划、会议纪要和知识整理。

适合人群：产品经理、项目负责人、学生和教师、内容策划、研究人员，以及需要先看整体结构的人。

AI 生成的节点仍然需要人工核对，导图能帮助组织思路，但不能自动证明内容正确。

### 流程图：适合表达业务、产品和技术流程

流程图支持自然语言生成、Mermaid 转换和手动绘制。自然语言适合快速出草稿，Mermaid 适合明确节点和连线，手动绘制适合最后调整布局。

适合业务流程、用户路径、审批链路、技术架构草图、排障步骤和团队 SOP。

适合人群：产品经理、研发、运营、咨询顾问、项目管理者，以及需要让团队对流程达成共识的人。

完成后要沿每条分支从入口走到出口，检查遗漏路径、死循环、方向错误和没有标签的判断。

## 三、工作流工具：让资料、任务和结果可以复用

### 工具箱与 Skill/Agent：适合重复做同一类工作的人

工具箱可以集中访问提示词参考、动作参考、聊天、单图生成、批量出图、视频和知识管理等能力。Skill/Agent 更适合把一个固定场景写成角色、输入、步骤和输出格式。

适合品牌视觉生产、批量出图、固定格式的内容生成、团队 SOP 和个人工作流沉淀。

适合人群：有重复生产需求的运营和设计团队、需要统一输出格式的组织、熟悉 AI 工作流的高级用户和独立开发者。

建议先在小任务中验证流程，再把它沉淀成可复用方法。不要把未经检查的生成结果直接当作团队规范。

### 知识库：适合把经验和资料留下来

知识库支持目录、标签、检索、Markdown 笔记以及导入导出，可以整理产品资料、品牌规范、提示词、项目笔记和自定义 Skill。

适合产品资料库、研究笔记、团队 SOP、提示词库、项目知识和长期内容积累。

适合人群：内容团队、产品与研发团队、教师、研究人员和希望把经验沉淀下来的个人用户。

AI 归纳出的内容要检查来源和范围。API Key、Cookie 和未经脱敏的客户数据，不应放进可以导出的知识库。

### 任务队列：适合批量生成和管理异步任务

任务队列可以查看生成中、失败和已完成任务，读取错误信息，插入画布、下载、重试或批量处理。

适合批量出图、视频任务、多版本提示词对比、历史结果回看和失败任务排查。

适合人群：批量生产素材的运营和设计团队、需要管理多个异步任务的创作者、产品测试人员和技术支持人员。

重试前先排查重复提交、权限、余额和参数问题。完成一批任务后，抽查文件是否能打开、尺寸是否正确、是否有重复结果。

### 命令面板：适合高频操作的人

命令面板通常可以用 `Cmd + K` 或菜单打开。输入功能名称，就能快速找到任务队列、素材库、导出和设置等入口。

适合工具较多、菜单层级较深、需要快速切换工作区的场景。

适合人群：高频使用者、设计和研发人员、需要用键盘加快操作的专业用户。

删除素材、清空画布和清理数据前，先阅读确认提示。

## 四、资产管理：让生成结果走到交付

### 图片预览与编辑：适合在工作区完成轻量修图

图片预览支持查看原始大小和细节；编辑功能包括裁剪、去白边、滤镜、亮度、对比度、饱和度、色温和锐化等调整。

适合生成图二次构图、准备不同社媒比例、统一一组图片效果和交付前检查。

适合人群：运营和设计人员、电商团队、社媒创作者，以及希望减少工具切换的人。

重要图片建议先另存为，保留原始版本。

### 素材库：适合管理和复用图片、视频

素材库是上传和生成内容的集中位置，可以筛选、搜索、预览、插入画布和选作参考图。

适合品牌资产管理、历史结果复用、项目素材整理和多版本视觉资产管理。

适合人群：持续产出内容的个人创作者、品牌与电商团队、需要管理大量视觉资产的设计人员。

手册说明这类数据主要保存在当前浏览器。换浏览器、清除网站数据或使用隐私模式前，要先完成备份。

### 导出与导入：适合交付、备份和迁移

PNG/JPG 用于发布，`.drawnix` 项目文件用于继续编辑，ZIP 备份用于迁移项目、素材和提示词历史。三种文件的用途不同。

适合发布图片、交付源文件、换设备、换浏览器和保存重要项目。

适合人群：所有长期使用者，尤其是需要跨设备工作或管理重要项目的团队。

自动保存不等于跨设备同步。重要里程碑请主动导出，并在分享前移除不应公开的素材、提示词和凭证。

## 五、配置与排查：先把边界弄清楚

### API 配置与设置

设置里可以管理供应商、接口类型、图片接口格式、API 地址、API Key、模型预设、主题、语言和画布偏好。

适合第一次接入模型、切换供应商、保存常用模型组合和处理“模型看得到但任务跑不通”的问题。

适合人群：OpenTu 新用户、自带 API 配置的创作者、管理多个模型预设的高级用户和技术接入人员。

第一次配置后，建议只加载少量模型，完成一次最小任务，确认模型可选择、任务有状态、结果能打开。API Key 是账户凭证，不要放进公开截图、笔记或项目文件。

### 问题排查

当出现 401/403、页面空白、素材不显示、数据看起来丢失或视频任务长时间等待时，先记录页面、浏览器、时间、模型、任务 ID 和错误码。

适合任何遇到问题的用户，尤其是批量生产团队、技术支持人员和需要稳定交付的人。

先检查网络、Key、服务端点、模型权限、余额和浏览器存储；不要在原因不明时连续重试，也不要提交完整 Key、Cookie 或未脱敏日志。

## 哪些人最适合使用 Opentu？

Opentu 最适合下面四类人：

1. 内容创作者：需要图片、视频、脑图和素材归档，持续产出内容。
2. 产品与运营人员：需要把创意、方案、流程图和交付物放在一起。
3. 设计与品牌团队：需要管理参考图、生成结果和多个视觉版本。
4. 独立开发者与小团队：希望把提示词、知识、任务和重复工作流沉淀下来。

如果你只是偶尔生成一张图片，单点生图工具可能已经够用；如果你经常经历“想法 → 结构 → 素材 → 修改 → 交付 → 复用”，画布工作区的价值就会更明显。

## 第一次使用，建议这样开始

打开 [Opentu 工作台](https://agent.gpt88.cc/opentu/)，先完成当前账号可用的 API 和模型配置。然后只做一个小任务：生成一张图片，或建立一张思维导图；到任务队列确认状态；把结果放回画布；补充文字或箭头；最后导出图片，并为重要项目做备份。

第一次成功的标准不是“看到了一个生成按钮”，而是模型可选择、任务有明确状态、结果可以打开、画布可继续编辑、导出文件可用、重要数据有备份。

想查看具体菜单和操作步骤，可以继续阅读 [Opentu 用户手册](https://agent.gpt88.cc/opentu/user-manual/index.html)。
