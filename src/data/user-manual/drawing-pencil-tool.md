## 从一条线开始

点击画笔图标或按 `P`。在画布上按住鼠标左键，拖出笔迹后松开；再次按下即可画下一条。

## 选择笔触与样式

展开画笔旁的小箭头，按用途选择：毛笔适合有粗细变化的笔迹，钢笔适合均匀轮廓，马克笔适合半透明标注。选定工具后，在工具栏调节颜色与粗细。

先在空白区域画一条测试线，检查颜色、线宽和透明度，再绘制主体。设备是否支持压感取决于硬件与浏览器；按住 `Shift` 可尝试约束为直线。

## 修正与复用

使用橡皮擦图标或 `E` 擦除笔迹。若想移动整条线，按 `V` 选中，再拖动或用方向键调整。已画出的线条作为元素处理，可以复制、删除和撤销。

| 操作 | 快捷键 |
| --- | --- |
| 画笔 / 钢笔 | `P` / `Shift + P` |
| 橡皮擦 | `E` |
| 选择 / 移动视野 | `V` / `H` |
| 复制 / 粘贴 | `Ctrl/Cmd + C` / `Ctrl/Cmd + V` |
| 删除选中线条 | `Delete` 或 `Backspace` |

放大检查线条边缘，确认绘制结果，再按[导出指南](/docs/user-manual/advanced-export-import/)保存。需要反复使用的标注可先复制，保留一份原始版本。
