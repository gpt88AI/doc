想免费获得没有可见 Gemini 角标的 Nano Banana 图片，先在 Google AI Studio 做一张小样。Google 将 AI Studio 列为无可见标记的开发工具入口，其定价页也说明 AI Studio 在可用地区可免费使用；但实际可用性仍受地区、账号和额度影响。

这和 Gemini 免费版、图像 API 是三套不同的使用合同：Google 当前公开分流中，免费与 Google AI Pro 消费端输出保留可见 Gemini 标记；当前 Nano Banana 图像 API 定价行没有 Free Tier，API key 也不等于免费图片额度。无论画面是否有角标，Google 生成图片仍保留 SynthID。

先按用途选路：只做草稿，可以接受 Gemini 免费版的可见标记；要免费验证干净可见输出，先试 AI Studio；要代码、日志或批量控制，按付费 API 合同规划并在生产前验证实际输出；如果图片上的标记属于图库、平台、客户或他人权利，停止处理，取得许可或替换素材。

## 先看结论：四条路线不是同一种“免费”

截至 2026 年 7 月 16 日，Google 的公开材料给出的边界很清楚：**AI Studio 免费使用、Gemini 消费端免费额度、Gemini API Free Tier 和无可见标记输出，不能互相替代。** 其中 Nano Banana Pro 产品说明把免费及 Google AI Pro 消费端与 Google AI Ultra、AI Studio 等开发工具分开；[Gemini API 定价页](https://ai.google.dev/gemini-api/docs/pricing)则把 AI Studio 的可用地区免费使用，与图像模型 API 的付费输出行分开列示。

## 为什么 AI Studio 免费，不等于 Nano Banana API 免费

[Gemini API 图像生成文档](https://ai.google.dev/gemini-api/docs/image-generation)当前列出的稳定图像模型包括 `gemini-3.1-flash-lite-image`、`gemini-3.1-flash-image`、`gemini-3-pro-image`，以及旧一代 `gemini-2.5-flash-image`。在对应定价行里，这些图像输出目前都没有 Free Tier。创建 API key、打开 AI Studio 或看到某个文本模型有免费层，都不能推出图像 API 请求也免费。

更准确的理解是：

-   **AI Studio 是交互式开发工具入口。** Google 允许在可用地区免费使用它，适合先验证提示词、构图和输出外观。
-   **Gemini API 是按项目和请求执行的开发合同。** 图像输出要看具体 model ID、分辨率、账单项目和当日定价行。
-   **Gemini Apps 是消费端合同。** 免费额度、付费计划、默认模型和可见标记行为由应用端决定，不等于 API 配额。
-   **“无可见标记”只描述画面表层。** 它不表示图片没有 SynthID，也不表示参考素材、人物、商标或输出自动获得商业许可。

因此，免费小样的动作应该很小：打开 AI Studio，选当前可用的图像模型，用不含敏感素材的简单提示词生成一张，下载后检查角落与画面，再记录账号、模型、日期和输出。只有这一步符合预期，才值得继续投入提示词和参考图。若界面不可用、额度耗尽或输出行为不同，就把它视为当前账号的真实边界，而不是去寻找所谓“无限免费”的旁路。

## 可见 Gemini 标记、SynthID、元数据和权属水印有什么区别

中文里的“水印”常把四类东西混在一起，但它们对应四种动作。

| 标记类型                     | 你能否直接看见 | 它在说明什么                           | 合适动作                           |
|------------------------------|---------------:|----------------------------------------|------------------------------------|
| 可见 Gemini 标记             |             能 | 某个 Google 消费端或输出路线的画面标记 | 换到符合要求的入口重新生成或导出   |
| SynthID                      |       通常不能 | Google AI 生成内容的来源信号           | 保留；不要把规避它当成交付目标     |
| 文件元数据                   |         不一定 | 工具、导出和文件层信息                 | 按交付与审计要求保留，不要一律删除 |
| 图库、摄影师、平台或客户水印 |             能 | 所有权、许可、来源或审核状态           | 停止，取得授权或更换素材           |

Google 的图像文档明确说明，生成图片包含 SynthID。也就是说，“画面上没有 Gemini 角标”和“图片没有来源信号”不是同一件事。Google 还提供了 [Gemini 中的 SynthID 验证说明](https://support.google.com/gemini/answer/16722517?hl=zh-Hans)：在支持的账号与地区，可以把图片交给 Gemini，询问它是否由 Google AI 生成。这种验证能力正说明 SynthID 的角色是来源识别，而不是挡住画面的 Logo。

商业交付也不能只看角落是否干净。还要确认参考图是否有上传权、人物和商标是否可用、目标平台是否要求 AI 披露、客户是否需要生成记录，以及当前入口的条款是否允许目标用途。无可见标记不是自动授权，更不是“保证商用安全”。

## 已有图片带可见标记，怎样恢复最稳妥

已有图片先不要进入“擦掉”的思路。按以下顺序恢复，通常能保住构图意图，也更容易解释来源。

1.  **重新生成。** 保存原提示词、参考图和关键参数，在 AI Studio、Ultra 或已核对的开发路线重新生成。
2.  **重新导出。** 如果原项目仍在，先检查是否能从正确计划或正确工具重新导出，不要修改成图像素。
3.  **重建构图。** 无法复现原图时，提取主体、镜头、色彩和文字层级，重新写提示词；不要把带标记文件当成需要修补的最终底图。
4.  **把合法裁切当作版式选择，而非规避手段。** 只有图片属于你、裁切不误导、也不移除必须保留的披露或权属信息时，才讨论重新构图。
5.  **替换素材。** 图库、平台、摄影师、客户或来源不明的标记，直接换成已授权素材。
6.  **停止。** 目标是移除 SynthID、真实性标记或他人的权属标记时，不继续处理。

如果原图非常重要但无法复现，先回答三个问题：谁拥有它、哪一层标记造成问题、最终用途是否允许重新生成。只要其中一个答案不清楚，就不要把它交给自动去水印服务。普通的背景替换、删物体和构图修改属于另一类任务，可以参考 [Nano Banana 图像编辑指南](/docs/blog/nano-banana-inpaint)。

## 开发者上线前要验证哪些项目

API 路线的价值是代码、日志、批量控制和可复现请求，不是“默认免费”或“永远无角标”。上线前至少完成一次同路径验证：使用将要部署的 project、model ID、输入类型、分辨率和保存逻辑，生成一张低风险小样，再检查返回状态、账单记录、保存后的像素尺寸、可见标记和来源记录。

建议在日志里保留：

-   provider 与 endpoint；
-   稳定 model ID，而不是旧 preview 名称；
-   project、region 或账单归属；
-   请求时间、输出尺寸与最终保存路径；
-   成功、失败、重试和内容安全状态；
-   上线前的定价页与文档复核日期。

不要把 `gemini-3-pro-image-preview` 继续写进新集成，它不是当前稳定 Nano Banana Pro model ID。也不要因为 AI Studio 免费，就把生产 API 预算写成零。具体配额排查可参考 [Gemini 3 Pro Image API 配额限制指南](/docs/blog/gemini-3-pro-image-api-quota-limits-zh)。

## 第三方“免费无水印”服务，先要求六项证明

第三方页面可以提供便利，但页面标题不能证明它调用了哪个上游，也不能证明免费额度、隐私和输出权利。没有以下六项证据时，不把它当成推荐路线：

1.  **上游证明：** 明确写出当前模型与 provider，而不是只使用 Nano Banana 名称。
2.  **费用证明：** 免费是一次性试用、每日额度、排队预览还是可下载成图；失败和重试怎样计费。
3.  **输出证明：** 用同一账号实际生成并检查下载文件，不只看营销截图。
4.  **隐私证明：** 输入、参考图和输出保存多久，是否用于训练，如何删除。
5.  **权利证明：** 输出条款、参考素材责任、商业用途和争议处理写在哪里。
6.  **支持证明：** 模型下线、任务失败、扣费异常和账号问题由谁处理。

特别警惕“永久免费、无限量、永久无水印、保证商用、不封号、固定成功率”这类无法由当前条款和实际输出共同证明的承诺。即使某个服务今天送 credits，那也是它自己的促销合同，不是 Google 图像 API 的 Free Tier。

## 商业交付前的最小检查单

-   图片由你的账号、团队或客户授权路线生成。
-   上传的人物、Logo、产品图和参考素材有处理权限。
-   最终入口已经用一张小样验证过可见标记与输出尺寸。
-   需要代码或批量时，使用稳定 model ID，并保存请求与账单日志。
-   不把 SynthID、权属标记或真实性标记列为编辑目标。
-   客户需要 AI 披露、生成记录或源文件时，交付包里一起保留。
-   第三方路线只有在上游、费用、隐私、权利、输出和支持都清楚后才进入生产。

这套检查的核心很简单：**先选入口再生成，胜过先生成再擦除；无可见角标与保留来源可以同时成立。**

## 常见问题

### Google AI Studio 是永久免费、无限量的吗？

不能这样承诺。Google 当前定价页说明 AI Studio 在可用地区可以免费使用，但地区、账号、模型和额度会变化。把它作为免费小样入口，并在每次重要项目开始前验证当前可用性；不要把“可免费使用”扩写成“无限量永久免费”。

### 有 Gemini API key，就有免费 Nano Banana 图片额度吗？

没有这个推论。API key 是身份凭证。当前 Nano Banana 图像模型的 API 定价行没有 Free Tier；是否计费要看具体 model ID、请求和账单项目，而不是是否成功创建了 key。

### 为什么 Gemini 免费版的图片会有可见标记？

可见标记由消费端入口和计划决定。Google 对 Nano Banana Pro 的公开分流把免费及 Google AI Pro 消费端列为保留可见 Gemini 标记的路线，把 Ultra 与 AI Studio 等开发工具列为无可见标记路线。界面和计划会变化，最终图仍应先做小样确认。

### 没有可见 Gemini 角标，图片里还有 SynthID 吗？

有。Google 说明其生成图片包含 SynthID。SynthID 是不可见来源信号，不是角落 Logo；无可见标记输出不等于移除来源证明。

### 旧图已经带角标，能直接用去水印工具吗？

优先不要。自有生成图先换入口重新生成或重新导出；不可复现时重建构图。图库、平台、摄影师、客户或来源不清的标记要先解决授权；SynthID 和真实性标记不作为移除目标。

### 第三方网站写着 free without watermark，可以信吗？

标题只能证明它在做营销。至少核对上游、免费范围、下载文件、隐私、输出权利和支持边界，并用低风险小样验证。第三方 credits 也不等于 Google 官方 API 免费层。

### 商业项目应该选 AI Studio、Ultra 还是 API？

一张或少量小样先用 AI Studio 验证；消费端最终创作可评估 Ultra；需要代码、批量、日志和服务端控制时使用付费 API；需要 GCP 治理时再评估 Vertex AI。无论选哪条路，参考素材权利、平台规则、客户披露与 SynthID 边界都要单独确认。
