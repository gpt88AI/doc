这些属于转发作者对 Creao 安装版的描述。帖子没有提供可复现测试、任务配置或质检标准；本文也无法从公开材料核实该 Creao 版本新增的字幕、拼接和检查能力。可核实的上游项目是 [kaomei/stickman-video-director](https://github.com/kaomei/stickman-video-director)：其 README 描述的是生成脚本、导演提案和分段视频提示词，再由 Flow 等视频工具生成片段、交由剪映等软件加字幕与剪辑。两者不能直接视作同一个功能版本。

## 工作流拆成四段

CrazyKaomei 在[配套长文](https://x.com/CrazyKaomei/status/2102311241046008268)中，把自己的流程概括为找选题、搭故事结构、生成视频、人工组装。结合上游 README，可以按四个阶段理解：

| 阶段 | 主要工作 | 人需要确认什么 |
| --- | --- | --- |
| 选题与资料 | 找到适合动画讲解的主题，整理来源材料和受众问题 | 主题是否有真实信息支撑，数据和时效性是否核实 |
| 故事与导演提案 | 组织开场、递进、转折和结尾；设计旁白、画面动作、镜头、声音 | 事实有没有被夸大，叙事是否清楚，是否有不当模仿或版权问题 |
| 分段生成 | 选画风、时长和横竖屏比例，确认提案后生成逐段提示词，再交给视频生成工具 | 每段人物、道具、配音和镜头能否衔接，提示词是否对应已批准的提案 |
| 剪辑与验收 | 拼接片段、添加字幕和声音，检查导出效果 | 从头播放成片，检查字幕、事实、音画、转场和手机端可读性 |

上游 README 的描述是“先拿导演提案，再确认并生成提示词”。它列出 4 大画风、6 种视觉方案，支持 16:9 与 9:16；默认时长为 60 秒，也可按 10 秒整数倍指定。项目样例将每段设计成约 10 秒的提示词，再由 Google Flow 等工具生成。具体工具版本、时长和费用应以各平台当前界面为准。

## 导演提案是人工把关的关键点

自动生成脚本并不等于自动完成一条可发布的视频。上游流程保留了明确的确认步骤：先选择主题设置、画风、画幅和时长，再检查故事结构、分段旁白、动作、镜头与声音建议；确认后才输出视频提示词。这样做的价值是把大改放在成本较低的阶段，例如主题方向不对时，不必先生成多个片段再推倒重来。

审提案时可用这份短清单：

- **事实**：数字、历史事件、因果关系和引述是否有可靠出处？不确定内容是否被清楚标出？
- **叙事**：开头提出的问题是否真的会在后面回答？每一段是否推进了新信息，而不是反复制造悬念？
- **镜头**：旁白说到的对象是否在画面里出现？人物、服饰、道具和场景是否保持一致？
- **声音与字幕**：语速是否适合目标时长？专名、数字和双语字幕是否容易读对？
- **生成限制**：视频模型能否稳定生成要求的角色动作、文字和连续场景？必要时能否拆成更短镜头？

生成后仍要逐段检查，再看一遍完整导出文件。自动质检可以帮助发现格式或明显缺陷，但不能代替核对来源、叙事准确性、字幕错误和内容是否误导观众。

## “复刻结构”要保留抽象方法

配套长文主张研究少量视频表现突出的新频道，并拆解其开场、铺垫、转折、解释和收尾。把这种方法用于自己的主题时，应该只借鉴抽象的叙事技巧，例如“提出问题—建立背景—呈现证据—解释原因—总结”，不能照搬原视频台词、独特表达、镜头设计、视觉角色或音乐，再只替换名词就发布。

更稳妥的做法是从多个来源总结通用结构，为自己的主题独立查证资料和撰写脚本；保留来源记录，区分事实、推断和观点。长文中关于某频道播放量、广告收入、成本以及火柴人画风更易留住观众等说法均来自作者转述或经验判断，并非本文独立核实。个别频道的高播放量不能证明该套路可重复，更不能作为收入预测。

## 开源 Skill 与转发帖里的 Creao 版本

[上游 GitHub README](https://github.com/kaomei/stickman-video-director)将项目介绍为一个画风和导演 Skill，采用 MIT 许可。README 截至本文核对时列出的能力包括：根据主题生成脚本、英文旁白及中文参考、动作与镜头方案；先展示导演提案；确认后生成用于视频工具的分段提示词。README 同时明确区分 Skill 与视频生成工具：前者提供提案和提示词，后者生成视频，字幕与剪辑由剪映等工具完成。

转发帖里的 Creao Agent 带有独立安装入口，作者称它增加了自动字幕和质检。公开帖子没有链接其配置、源代码或检验记录，因此无法确认 Creao 版本具体采用什么模型、如何拼接、质检覆盖哪些问题，也不能用上游 GitHub README 替这些新增功能背书。不到 10 分钟出片同样是单次体验陈述，不代表其他主题、画幅或生成服务的稳定时长。

如果只想打磨选题、查证材料、整理旁白或导演提案，可以用 GPT88 的[统一大模型接口](https://doc.gpt88.cc/docs/guides/gpt88-ai-proxy/)辅助文本工作，并自行提供可靠来源、核对事实。它不等同于视频生成服务，也不会自动让 GitHub Skill 或 Creao Agent 兼容 GPT88 模型；生成画面、字幕和最终剪辑仍要按实际工具链分别完成和检查。

## 适合从小样片开始

火柴人和极简 2D 线条画面制作门槛较低，适合知识解释、历史故事、产品概念或简单情节演示。开始时先选一个可以核实的小主题，做 30 秒左右的试片，观察人物一致性、旁白节奏和字幕可读性，再决定是否扩大到更长内容。官方仓库也建议先确认提案并保留修改空间。

评估是否值得持续制作时，记录每条视频的选题来源、制作时间、修改次数、发布平台和一段时间后的实际表现。播放量受主题、频道基础、发布时机、平台推荐和观众反馈等多种因素影响，不能仅凭动画样式或工具安装来判断。
