OCR மோசமாக இருந்தால் crop, வெளிச்சம், angle சரிசெய்யுங்கள்; அடிக்கடி batch, offline packs அல்லது history தேவைப்பட்டால் dedicated app-ஐ மதிப்பிடுங்கள்.

## Phone photo-வில் language direction முதலில் அமைக்கவும்

Source English, target Spanish-ஐ manually set செய்யுங்கள். சிறிய சொற்கள், brand names, mixed labels உள்ள படங்களில் auto-detection தவறலாம். Text-ஐ பெரிதாக வைத்துக் கொண்டு phone-ஐ நேராகப் பிடித்து glare, shadow, backlight தவிர்க்கவும். முழு poster-ஐ அல்ல, தேவையான sentence-ஐ மட்டும் தேர்வு செய்யுங்கள். Original gallery file-ஐ import செய்யுங்கள்; screen-ஐ மீண்டும் photograph செய்தால் blur, moiré, angle distortion அதிகரிக்கும். Offline பயன்படுத்த முன் English மற்றும் Spanish packs download செய்து non-sensitive image-ல் சோதிக்கவும்.

## Computer screenshots-க்கு web image mode

Digital screenshot, scan, product image அல்லது manual-ஐ phone மூலம் மீண்டும் படம் எடுக்க வேண்டாம். தெளிவான single-page layout-க்கு web image mode பொருத்தமானது. Columns, tables, handwriting, rotated text அல்லது சிறிய எழுத்து இருந்தால் paragraph/column தனித்தனியாக crop செய்யுங்கள். Backup OCR அதிக accurate, private அல்லது unlimited என்று கருத வேண்டாம். Original image, recognized English, final Spanish மூன்றையும் சேர்த்து வைத்திருங்கள்.

## OCR மோசமாக இருந்தால் முதலில் படத்தைச் சரிசெய்யவும்

Missing text என்றால் crop சிறியதாக இருந்தாலும் முழு sentence இருக்கட்டும்; தவறான எழுத்துகளுக்கு blur, glare, tilt சரிசெய்யுங்கள்; merged columns-ஐ பிரிக்கவும்; handwriting-ல் தெளிவான line மட்டும் crop செய்யவும். Numbers, dates, units, dosage, proper nouns-ஐ original படத்துடன் சரிபார்க்கவும். `must`, `not`, `unless`, `before` தவறாக அறியப்பட்டால் obligation மாறிவிடலாம்.

## Dedicated app எப்போது தேவை

தொடர்ச்சியான பணியில் offline packs, history, batch, copy management நேரம் சேமிக்கும். Install முன் ads, trial/auto-renewal, cloud upload, retention, deletion, offline support, updates ஆகியவற்றைப் பாருங்கள். Clear sign, screenshot, non-sensitive invoice crop, low-light photo, multi-column text ஆகியவற்றில் 3–5 tests செய்யுங்கள். Download count அல்லது “100+ languages” accuracy நிரூபிக்காது.

## Private images-ஐ முதலில் பாதுகாக்கவும்

IDs, invoices, medical records, contracts, client screenshots, school files, addresses, QR codes முழுவதையும் upload செய்ய வேண்டாம். தேவையான English-ஐ மட்டும் crop செய்து பெயர், account, face, barcode, amount, file number redact செய்யுங்கள். Context நீங்கினால் key sentences-ஐ manually type செய்யுங்கள். Legal, medical, financial, school content-க்கு machine translation draft மட்டுமே; direct submission அல்ல.

## FAQ

### முதலில் எந்த tool?

ஒரே படத்திற்கு Google Translate; phone-ல் camera/gallery, computer-ல் web image mode.

### இது free-ஆ?

Basic one-off translation பெரும்பாலும் free; ads, offline, batch, export, advanced OCR-க்கு வரம்புகள் இருக்கலாம்.

### Google Translate படத்தில் English-ஐ அறியுமா?

ஆம்; mobile camera/gallery மற்றும் web image upload பயன்படுத்தலாம். English→Spanish manually set செய்யுங்கள்.

### Recognized English தவறாக இருந்தால்?

முதலில் crop, angle, light, glare சரிசெய்யுங்கள். OCR தவறினால் Spanish-மும் நம்பகமல்ல.

### Google Translate அல்லது Yandex OCR?

Google-ல் தொடங்குங்கள்; upload/layout சிக்கல் என்றால் இரண்டாவது OCR route. Spanish இயல்பாக உள்ளதா என்பதற்குப் பதிலாக English recognition சரியா பாருங்கள்.

### Photo-translation apps பாதுகாப்பானவையா?

Default-ஆக நம்ப வேண்டாம். Privacy policy படித்து sensitive image-ஐ crop/redact செய்யுங்கள்.

### Internet இல்லாமல் பயன்படுத்தலாமா?

சில apps language packs பிறகு offline camera வழங்கும்; முன் non-sensitive image-ல் test செய்யுங்கள்.

### Handwritten English?

சில நேரங்களில் முடியும், ஆனால் குறைந்த நிலைத்தன்மை. தெளிவான ஒரு line crop செய்து, தவறினால் manually type செய்யுங்கள்.
