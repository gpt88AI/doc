Official ChatGPT-ஐத் திறந்து conversation-ல் image request எழுதுங்கள், அல்லது More menu-ல் Images திறக்கவும். Prompt-ல் purpose, subject, scene, composition, aspect ratio, தேவையான text மற்றும் unchanged items எழுதுங்கள். Generate ஆனதும் உடனே publish செய்ய வேண்டாம்; zoom செய்து பாருங்கள், ஒன்று அல்லது இரண்டு defects மட்டும் மாற்றுங்கள், Save செய்து local file-ஐ verify செய்யுங்கள்.

UI names, quotas மற்றும் Images with thinking availability device, plan, region, rollout மற்றும் account state-ஐப் பொறுத்து மாறலாம். Fixed images-per-day எண்ணிக்கையை உங்கள் account message-க்கு மேலாக நம்ப வேண்டாம்.

## Official ChatGPT-ஐ உறுதி செய்யுங்கள்

Third-party pages பெயரில் ஒத்திருக்கலாம்; model, privacy, upload rules, rights மற்றும் limits மாறுபடும். Account மற்றும் plan, available image mode, limit message மற்றும் retry time ஆகியவற்றைப் பாருங்கள். Free user image quota என்பது API credit அல்ல.

## ஏழு படி workflow

1. Delivery conditions எழுதுங்கள்: channel, audience, subject, orientation, crop மற்றும் தவறக் கூடாத text/facts.
2. Natural paragraph prompt: purpose + subject + scene + composition + aspect ratio + style + required text + forbidden changes.
3. Complex request-க்கு நேரம் கொடுக்கவும்; மீண்டும் மீண்டும் submit செய்ய வேண்டாம்.
4. Thumbnail அல்ல, full image-ஐ zoom செய்து subject, hands, faces, logos, text, numbers, dates மற்றும் crop சரிபார்க்கவும்.
5. ஒரே நேரத்தில் ஒன்று அல்லது இரண்டு variables மட்டும் மாற்றி keep list எழுதுங்கள்.
6. Text-heavy poster-ல் அழகை விட சரியானதை முன்னிலைப்படுத்துங்கள்; price, date, medical/legal text மற்றும் specs-ஐ source-ல் verify செய்யுங்கள்.
7. Save பிறகு format, aspect ratio, version, filename மற்றும் target page crop-ஐச் சரிபார்க்கவும்.

## Uploaded image editing

உங்களுடைய அல்லது licensed asset-ஐ மட்டும் upload செய்யுங்கள். ID, credentials, private chats, confidential business material அல்லது intimate images-ஐ consent இல்லாமல் upload செய்யாதீர்கள். Whole-image editing lighting/background-க்கு; region editing object அல்லது local text-க்கு. Selection முழுமையாக precise ஆகாமல் இருக்கலாம்; ஒவ்வொரு edit பிறகும் முழு image-ஐப் பாருங்கள்.

## Pre-publish check

Thumbnail-ல் topic தெளிவா? Text character-by-character சரியா? Logo, quote, map, statistic அல்லது product spec உருவாக்கப்பட்டதா? Asset licensed-ஆ? Real-person likeness-க்கு consent உள்ளதா? Downloaded file திறக்கிறதா, crop சரியா? தெளிவில்லையெனில் publish செய்ய வேண்டாம்.

## C2PA மற்றும் SynthID

ChatGPT, Codex மற்றும் OpenAI API images-ல் C2PA metadata மற்றும் SynthID watermark இருக்கலாம். அவை provenance clues; accuracy அல்லது legal ownership certificate அல்ல. Prompts, licenses, source facts, edits மற்றும் approval history-ஐப் பதிவு செய்யுங்கள்; provenance markers-ஐ அகற்ற வேண்டாம்.

## ChatGPT மற்றும் API வேறு contracts

App experience மற்றும் personal quota, API key, billing, errors, retries, storage, rate limits மற்றும் permissions ஆகியவற்றிலிருந்து வேறுபடும். App-ல் image உருவாகிறது என்பதால் free `gpt-image-2` API access நிரூபிக்காது. Automation அல்லது Batch-க்கு API documentation பயன்படுத்துங்கள்.
