Official ChatGPT खोलें और conversation में image request लिखें, या More menu से Images खोलें। Prompt में purpose, subject, scene, composition, aspect ratio, आवश्यक text और unchanged items बताएं। Generate होने के बाद तुरंत publish न करें: पहले zoom करके जाँचें, एक या दो defects बदलें, Save करें और local file verify करें।

UI names, quotas और Images with thinking की उपलब्धता device, plan, region, rollout और account state के अनुसार बदल सकती है। Online pages पर fixed images-per-day संख्या को अपने account के message से ऊपर न रखें।

## पहले official ChatGPT confirm करें

Third-party pages के नाम समान हो सकते हैं, पर model, privacy, upload rules, rights और limits अलग हो सकते हैं। Current account और plan देखें, उपलब्ध image mode देखें और limit message का retry time रिकॉर्ड करें। Free users को image tool quota मिल सकता है, लेकिन वह normal chat quota या API credit नहीं है।

## सात-step deliverable workflow

1. Delivery conditions लिखें: channel, audience, subject, orientation, crop और गलत नहीं होने वाले text/facts।
2. एक natural paragraph prompt दें: purpose + subject + scene + composition + aspect ratio + style + required text + forbidden changes।
3. Complex request को समय दें; बार-बार submit करने से request और quota tracking अस्पष्ट होती है।
4. Thumbnail के बजाय full image zoom करें: subject, hands, faces, logos, text, numbers, dates और crop जाँचें।
5. एक बार में केवल एक या दो variables बदलें और keep list लिखें।
6. Text-heavy poster में “pretty” से पहले “correct” रखें; कीमत, तारीख, medical/legal text और specs को source से verify करें।
7. Save के बाद file format, aspect ratio, version, filename और वास्तविक target page पर crop जाँचें।

## Uploaded image editing

केवल अपना या licensed asset upload करें। IDs, credentials, private chats, confidential business files या intimate images बिना consent upload न करें। Whole-image editing lighting, tone और background के लिए है; region editing object removal या local text के लिए। Selection precise न हो सकती है, इसलिए हर edit के बाद पूरा image देखें।

Editing prompt में change scope और keep list दोनों लिखें, जैसे: “केवल दाईं ओर का red cup हटाएं; face, hands, screen, lighting और ratio unchanged रखें।” Multiple references को image 1/image 2 और foreground/background/left/right के साथ स्पष्ट करें।

## पाँच मिनट की pre-publish check

Thumbnail में topic स्पष्ट है? Text character-by-character सही है? Logo, quote, map, statistic या product spec गढ़े नहीं गए? Uploaded asset licensed है? Real-person likeness में consent है? Downloaded file खुलती है और target channel crop नहीं करता? इनका उत्तर स्पष्ट न हो तो publish न करें।

## C2PA और SynthID

ChatGPT, Codex और OpenAI API images में C2PA metadata और SynthID watermark हो सकते हैं। ये provenance clues हैं, accuracy, legal ownership, unmodified status या context का certificate नहीं। Metadata हटना human authorship सिद्ध नहीं करता। Prompts, licenses, source facts, edits और approval history अपने records में रखें; provenance markers हटाने या safety policy bypass करने की प्रक्रिया न अपनाएं।

## ChatGPT और API अलग contracts हैं

ChatGPT app अनुभव और personal quota देता है। API में key, billing, request format, errors, retries, storage, rate limits और permissions अलग हैं। App में image बनना free `gpt-image-2` API access सिद्ध नहीं करता। Batch, API pricing या automation चाहिए तो API documentation से शुरू करें।
