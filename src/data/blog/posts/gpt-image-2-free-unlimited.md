**先说结论：Adobe Firefly 里有 GPT Image 2，不代表 GPT Image 2 对你的 Adobe 账号免费。** Adobe 的 Firefly Free 目前只承诺有限的每日生成和"部分模型"访问；官方合作模型页本身没有把 GPT Image 2 写成所有免费账号的固定权益。与此同时，OpenAI 官方 `gpt-image-2` API 明确不支持 API Free tier。

所以，"Adobe GPT Image 2 免费"不能只看一个"免费开始"按钮。你至少要同时看到：Firefly 中的模型名称、当前账号方案或积分、一次生成实际扣了多少、结果能否下载，以及上传素材的数据与权利边界。任何一项看不清，就把它当作尚未验证的体验入口，不要当作免费生产能力。

这不是价格对比表，而是一张**路线合同表**。它的验收标准很简单：读完后，你应该能回答自己究竟在用谁的产品、谁承担成本、免费边界在哪里，以及失败后找谁。如果仍只能回答"页面上好像写着免费"，就还不能上传真实资产。

## Adobe 到底确认了什么

Adobe 的 GPT Image 2 合作模型页确认的是产品路径：GPT Image 2 可作为合作伙伴模型进入 Firefly 相关工作流。Adobe 当前帮助页进一步列出它可出现在 Firefly 的 Text to image、Prompt to Edit Image、Firefly Boards 和 Firefly Graph 中。

这能证明"Adobe 提供了一个 GPT Image 2 产品入口"，但不能单独证明三个更强的结论：

- 不能证明你的地区和账号一定能看到该模型；
- 不能证明 Firefly Free 一定包含它；
- 不能证明一次看见模型名称后，生成、下载和商用条件都已满足。

Adobe Firefly 计划页把免费层描述为有限的每日生成，并使用"部分模型"这类范围表述。它没有给所有地区、所有免费账号一个永久的 GPT Image 2 权益承诺。计划页当前美国市场还展示到 2026-08-26 的促销和付费 Premium 权益；这是有地区、账号、套餐和截止日期的商业条款，不应改写成"中国用户现在免费不限量"。

Adobe 合作伙伴模型帮助页更新于 2026-07-24，给出了更具体但同样需要限定范围的信息：GPT Image 2 的低、中、高分辨率当前分别标为 5、20、80 个生成式积分；可用性可能因国家或地区而异，费率可以变化，套餐也可能调整。对你来说，账号里的实时模型与积分状态比搜索摘要更有决定权。

## 中国用户应该怎样核对

不要把全球英文页面等同于中国大陆账号验证。即使搜索时指定简体中文和中国市场，Adobe 官方结果也可能回落到全球英文页面；地区、账号类型、付款方式、企业策略和产品开放节奏都可能改变最终界面。

因此，中国用户最稳妥的第一步不是找"免登录镜像"，而是在自己的 Adobe 账号里检查以下四件事：

1. Firefly 模型选择器中是否真实出现 **GPT Image 2**；
2. 当前方案名称、生成式积分余额或每日生成提示是什么；
3. 选择低、中、高分辨率时，界面预告的积分消耗是否与帮助页一致；
4. 合作模型确认、地区提示、上传说明和下载按钮是否都能完成。

如果模型根本不出现，就把结论写成"当前账号不可用"，不要借共享账号、代注册、改地区或未知来源的 wrapper 绕过。这样做不能验证你的长期权益，反而会增加账号、付款、隐私和支持风险。

如果模型出现但界面没有说清扣费，先不要上传真实客户图。用一条不含个人信息、品牌机密或未发布素材的测试 prompt，记录生成前后的积分变化。只有账号内的实际扣费记录才能回答"我的账号是不是免费""这张图花了多少积分"。

## 一次低风险验证流程

这条流程的目标不是证明画质最好，而是验证**从模型可见到文件可交付**的完整路径。准备一条公开、无敏感信息的 prompt；如果必须测参考图，就使用你拥有完整权利、且不包含真人或客户资产的测试图。

### 第一步：从官方合作模型页进入 Firefly

确认浏览器地址属于 Adobe 官方域名，不要从第三方"免费 GPT Image 2"页面直接登录 Adobe 账号。在 Firefly 模型选择器里寻找 GPT Image 2，并记录页面日期、模型标签和所在工具。

如果只看到 Firefly 自有模型或其他合作模型，停止。不要因为 Google 摘要写着 GPT Image 2 就假设账号里也有。

### 第二步：在生成前读取账号与积分状态

打开账号方案或积分说明，记录余额、每日生成提示、分辨率选项和生成前预计消耗。Adobe 当前帮助页给出 5/20/80 个积分这一参考，但你的账号界面可能因地区、计划或调整而不同。

如果账号界面与帮助页不一致，以账号界面作为这次决策的实际状态，同时保留截图或文字记录。不要把一次促销期间的状态写成永久权益。

### 第三步：只用低风险输入跑一张

先选最低成本、最低风险的设置，用一条普通 prompt 生成一张图。不要在第一次验证里上传身份证件、真人照片、医疗材料、未发布产品、客户文件、内部设计稿或带版权争议的参考图。

如果页面要求确认合作伙伴模型条款，先读完再继续。无法理解数据会发送给谁、用于什么生成步骤时，就停止上传参考文件。

### 第四步：核对生成、扣费和失败提示

生成后记录三项结果：

- 是否得到与所选模型标签一致的可见结果；
- 生成前后积分差是多少；
- 失败时是否扣积分、是否显示可操作的错误原因。

只看到预览不算完成。排队、超时、安全拦截、地区阻断或积分不足都属于需要记录的失败分支，而不是"再多点几次试试"。

### 第五步：下载并检查交付条件

确认文件能下载或保存到你的目标工作流，检查分辨率、格式、画面内容、文字准确性和参考图遵循程度。对于商业项目，还要单独核对项目素材权利、合作模型条款、公司政策和本地合规要求。

只有模型可见、扣费清楚、结果可下载、输入输出风险可接受这四项同时通过，才能说"这个 Adobe 账号当前可以完成这条 GPT Image 2 工作流"。这仍不等于免费不限量，也不等于别人的账号有同样权益。

## Prompt 和参考图会发给谁

GPT Image 2 在 Firefly 中属于合作伙伴模型。Adobe 的合作模型说明明确区分了 Adobe 与合作伙伴：这些模型不是 Adobe 开发，用户需要判断模型是否适合自己的用途。为了完成生成，必要的文字 prompt 和参考文件会传给相应合作伙伴。

同一帮助页还说明，这些内容不会被用于训练合作伙伴的生成式 AI 模型或 Adobe AI 模型。这是重要信息，但它仍不是对所有隐私问题的完整回答。它不能替代你对账号类型、保留期限、访问权限、输出权利、企业合同、支持责任和特定行业要求的核对。

可以按风险把输入分成三档：

| 输入风险 | 示例 | 建议 |
| --- | --- | --- |
| 低 | 自己编写的普通 prompt、无人物无品牌的测试图 | 可用于首次流程验证，但仍记录所选模型和日期 |
| 中 | 已公开的品牌素材、自有产品图、准备发布的营销图 | 先核对商业用途、合作模型条款、内容凭证和公司政策 |
| 高 | 客户原图、真人照片、证件、医疗金融材料、未发布设计、受 NDA 约束文件 | 没有明确的数据、权限、保留和支持边界就不要上传 |

"Adobe 页面里能选到模型"只说明产品入口，不会自动把高风险输入变成低风险输入。

## Firefly、ChatGPT 和 API 为什么必须分开

很多"GPT Image 2 免费"内容把三条路线混成一句话：Adobe 能选模型、ChatGPT 能生图、OpenAI 有 API，于是得出"免费账号可以无限调用"。这三个事实没有这样的传递关系。

**Firefly 是 Adobe 的应用与积分合同。** 你在 Adobe 账号中选择合作模型，受 Firefly 计划、积分、地区和 Adobe 产品界面约束。

**ChatGPT 是 OpenAI 的应用合同。** 你在聊天界面手动生成图片，受 ChatGPT 账号当时的可用性与使用限制约束。想进一步理解 ChatGPT Images 2.0 的产品命名，可看 [ChatGPT Images 2.0 说明](/docs/blog/chatgpt-images-2-0/)。

**`gpt-image-2` API 是 OpenAI 的开发者合同。** [官方模型页](https://developers.openai.com/api/docs/models/gpt-image-2)列出 `gpt-image-2` 及快照 `gpt-image-2-2026-04-21`，用于图像生成和编辑，并明确 API Free tier 不支持。若你的问题只剩"官方 API 有没有免费层"，可以参考官方免费层专题。

三条路线可以使用相关的模型能力，但 payer、额度、日志、失败处理和支持对象不同。Adobe 积分不能当 OpenAI API 余额，ChatGPT 应用额度也不能变成服务器请求。

## 什么时候该付费，什么时候该停止

如果你的任务只是确认画面方向，一次低风险测试就足够。模型出现、扣费可见、结果可下载，即可判断是否值得继续，不需要为了"用足免费额度"上传更多真实素材。

如果要稳定生产、批量处理、接入客户产品、保留审计日志或控制重试，免费体验已经不是主要问题。你需要比较每个可接受输出的实际成本、失败计费、速率、延迟、存储与支持。下一步可看 [GPT Image 2 单张成本计算](/docs/blog/gpt-image-2-cost-per-image/)，而不是继续搜索"无限 wrapper"。需要统一接入 OpenAI、Google 等多路模型时，也可以走 GPT88 统一网关，具体价格与配额以 gpt88.cc 控制台为准。

遇到下面任一情况，应该停止当前路线：

- 模型标签缺失或生成后无法确认使用了哪个模型；
- 账号的免费权益、积分余额或单次扣费不可见；
- 页面要求上传真实素材，却说不清 prompt/参考图的传输对象与用途；
- 当前地区或账号不支持，必须借账号、改地区或依赖共享 key 才能继续；
- 结果不能下载，或失败、误扣费、退款和支持路径不清楚；
- 页面把限时促销、一次试用或每日额度包装成永久免费不限量。

停止不是失败，而是这张路线合同表给出的合格结论：当 owner、payer、limit、data 和 support 不能同时成立时，不应该把一次偶然成功升级为生产承诺。

## 常见问题

### Adobe Firefly Free 一定能用 GPT Image 2 吗？

不能这样确认。Firefly Free 当前只承诺有限的每日生成和部分模型访问；合作模型页证明 Firefly 有 GPT Image 2，但没有证明每个免费账号都包含它。请以自己的账号模型选择器和积分提示为准。

### GPT Image 2 在 Adobe 里一次要多少积分？

Adobe 帮助页在 2026-07-24 更新的表格中列出低、中、高分辨率分别为 5、20、80 个生成式积分。费率、计划和地区可能变化，实际生成前仍要看账号界面。

### 美国 Adobe 促销能套用到中国账号吗？

不能。美国计划页当前促销有市场、套餐、资格和 2026-08-26 截止日期。没有中国区账号页面的明确确认，就不要把它当作中国用户权益。

### 用 Adobe 的 GPT Image 2 会上传 prompt 和参考图吗？

为了完成合作模型生成，Adobe 说明必要的 prompt 和参考文件会传给相应合作伙伴。Adobe 同页表示这些内容不会用于训练合作伙伴生成式 AI 模型或 Adobe AI 模型，但你仍需核对保留、权限、权利和企业合规要求。

### Adobe Firefly 等于 OpenAI 官方 API 吗？

不等于。Firefly 是 Adobe 产品中的合作模型入口；`gpt-image-2` API 是 OpenAI 开发者平台的独立合同。两者的账号、账单、积分、日志和支持对象都不同。

### OpenAI GPT Image 2 API 有免费层吗？

当前官方模型页写明 API Free tier 不支持。ChatGPT 应用生图、Adobe Firefly 免费开始或第三方试用都不能改变这个 API 边界。

### 免登录的"Adobe GPT Image 2 免费版"值得用吗？

只要页面说不清模型 owner、payer、额度、数据处理、输出权利和支持，就不要登录、上传真实素材或把它接入生产。最多用公开 prompt 做低风险观察；任何共享账号、共享 key 或绕过地区限制的路径都不是可验证权益。

### 怎样才算验证成功？

在自己的账号里看到明确模型标签和积分状态，用低风险 prompt 完成一次生成，记录实际扣费，并成功下载符合要求的文件；同时确认数据与权利边界可接受。缺少其中任何一步，都只能算入口可见，不能算工作流完成。
