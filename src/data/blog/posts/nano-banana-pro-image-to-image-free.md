Nano Banana Pro 图生图可以有免费试用，但“每日免费积分”不是 Google 为所有入口统一发放的一笔额度。你在 Gemini 里看到的是账号、地区、套餐和实时用量共同决定的消费端限额；Google 官方 Gemini API 按价格页计费；第三方编辑器的注册赠送、签到或每日积分，则由那家平台自己制定规则。

所以，不要先记“每天 2 张、3 张还是 10 次”，先看数字出现在哪个页面。你可能会在教程、媒体摘要或第三方页面同时看到这些数字，但它们来自不同账号、套餐或平台，不能互相替代。Gemini 页面显示的剩余用量才是该账号当下的答案；创建 API key 不等于领取免费图片额度；第三方写的“每日积分”也不是 Google 官方配额。

| 你在哪条路线              | “免费”实际指什么                                 | 如何看每日额度                             | 现在适合做什么                           |
|---------------------------|--------------------------------------------------|--------------------------------------------|------------------------------------------|
| Gemini 网页或 App         | 账号内可用的消费端图片体验，受计划与实时限额影响 | 以当前账号页面提示为准，不承诺固定张数     | 先用公开、可丢弃的样图验证编辑效果       |
| Google 官方 Gemini API    | 按官方价格页计费的开发者路线                     | 不把 API key 当免费图像积分                | 适合自动化、批量处理和需要成本记录的工作 |
| 第三方 Nano Banana 编辑器 | 平台自己的注册赠送、签到、试用或订阅积分         | 只对该平台有效，并先查重置、过期和扣费规则 | 仅在条款、隐私、删除和授权说明清楚后试用 |

如果图片包含客户肖像、未发布产品、身份证件、医疗信息或儿童素材，先不要上传到身份和条款不清的第三方站。更稳妥的顺序是：用公开样图确认路线和结果，再决定是否进入已核验的账号或付费工作流；“免费方便”不能替代对上传责任的判断。

## 先把“免费”归到正确的发放方

后续判断只围绕一个问题展开：当前额度究竟由 Gemini 账号、Google 官方 API，还是第三方平台发放。把发放方分清，才有可能正确比较重置时间、图片质量、隐私、授权和最终成本。

这三条路线看起来都能“上传一张图再修改”，但它们不是同一个钱包，也不共享同一套规则：

-   **Gemini 网页或 App** 管的是消费端账号体验。能否编辑、使用哪个模型、还有多少用量，要看当前账号和当前页面。
-   **Gemini Developer API** 管的是开发者请求。模型 ID、分辨率和输出价格写在官方文档里，账单按 API 规则产生。
-   **第三方编辑器** 管的是自己的积分、订阅和上传合同。页面上写着 Nano Banana Pro，并不能单独证明后端模型、扣费方式或图片处理规则。

遇到任何“免费”宣传，先记下五个字段：发放方、额度类型、重置时间、适用模型、单次编辑扣多少。缺一项，就不要把它换算成确定的图片数。

## 为什么 2 张、3 张、10 次不能互相证明

公开教程和第三方页面常用一个醒目的固定数字回答“每天能做几张”，但这些数字常常来自不同时间、不同账号、不同套餐，甚至不同平台。把它们放在一起比较，就像把手机套餐流量、云服务代金券和商店积分加成一个余额：算式有结果，含义却是错的。

截至 2026 年 7 月 17 日，Google 的[中文 Gemini 图片帮助](https://support.google.com/gemini/answer/14286560?hl=zh-Hans)说明，Gemini 应用可以用 Nano Banana 2 编辑已生成图片、上传单张图片编辑，或结合多张上传图片生成新图；Nano Banana Pro 则是 Google AI 方案订阅者可用的“使用 Pro 重做”路线。官方页面没有把所有账号承诺成一个永久固定的每日 Pro 张数。

Google 的[中文用量限额说明](https://support.google.com/gemini/answer/16275805?hl=zh-Hans)还强调，Gemini 应用的用量是按算力管理的，会考虑提示复杂度、所用模型与功能、对话长度等因素。页面在 2026 年 7 月 17 日显示，相关限额按时间窗口刷新，并可能继续受周限额约束。对读者真正有用的结论不是背一个数字，而是打开当前账号确认：

1.  当前页面显示的是 Nano Banana 2，还是提供“使用 Pro 重做”；
2.  当前账号属于免费体验、Google AI 付费方案，还是工作/学校账号；
3.  页面给出的限额或恢复提示是什么；
4.  这次任务是试效果，还是必须稳定交付的生产工作。

教程里的历史数字可以帮助理解可能的量级，不能代替当前账号页面。账号今天成功生成一张 Nano Banana 2 图片，也不能据此写成“免费获得了一张 Nano Banana Pro 图片”。

## 上传参考图的最短安全流程

先别拿客户素材测试。用一张自己拥有、可以公开、丢失也没有损失的样图，按下面顺序走一遍：

1.  **先判断图片是否敏感。** 有客户肖像、身份证件、合同、病历、未发布产品、内部数据、儿童信息或受许可限制的素材，先停止上传。
2.  **优先查看官方消费端。** 在 Gemini 当前账号里确认能否上传编辑，以及页面实际显示的模型和用量提示。
3.  **写下额度发放方。** 账号限额、API 账单、注册赠送和每日签到不是同一种额度。
4.  **只有分母明确才换算。** 同一页面必须同时说明可用积分、所选模型与分辨率、编辑模式和单次扣分。
5.  **第三方先查条款再上传。** 至少查图片保留与删除、输出授权、水印、支持渠道和失败是否退还积分。
6.  **检查一次失败的代价。** 超时、内容审核拦截或生成失败，是否仍扣积分？页面没说，就按“可能扣除”预留余额。
7.  **正式任务换到可解释的路线。** 需要批量、日志、固定模型、隐私承诺或售后支持时，不要把一次免费试用当生产合同。

这个流程的目的不是找到“积分最多”的站，而是用最低风险确认编辑指令、模型能力和成本结构。公开样图验证成功后，再决定真实文件是否值得进入该路线。

## Gemini 消费端：适合先试，但要看当前模型

对于一张非敏感样图，Gemini 网页或 App 通常是更直接的起点。官方中文帮助明确支持上传图片进行编辑，也说明普通图片生成与编辑主要使用 Nano Banana 2；订阅 Google AI 方案后，在符合条件的页面中可以用 Nano Banana Pro 重新生成并增加细节。

这一区分会影响三个常见判断：

-   **免费能编辑，不等于免费使用 Pro。** 如果页面显示 Nano Banana 2，就按 Nano Banana 2 记录结果。
-   **看到 Pro 入口，不等于拥有无限 Pro 次数。** “使用 Pro 重做”依赖付费资格和当前用量；如果 Nano Banana 2 当日图片配额已经用完，官方帮助提示也无法继续用 Pro 重做。
-   **账号可用，不等于素材适合上传。** 工作或学校账号可能适用不同许可；涉及客户或受监管内容时，还要满足所在组织的合同与数据要求。

如果目的只是验证“把背景换成白色”“保留人物、改衣服颜色”之类的指令，公开或合成样图足够。若结果要直接交付客户、包含复杂文字排版，或必须复现同一模型与分辨率，就该考虑付费、可记录的路线，而不是反复寻找另一个免费入口。

## 官方 Gemini API：API key 只是凭证

创建 API key 只解决身份验证，不会自动产生免费图片输出额度。API 的优势是可以明确模型 ID、分辨率、请求日志和自动化流程；代价是需要接受开发者计费与数据处理要求。

Google 的[Gemini Developer API 中文价格页](https://ai.google.dev/gemini-api/docs/pricing?hl=zh-cn)在 2026 年 7 月 17 日显示，下面两个当前图片模型的标准层级都没有免费图片层级：

| 官方模型                                  | 免费层级 | 当日页面列出的标准图片输出价格                                              |
|-------------------------------------------|----------|-----------------------------------------------------------------------------|
| `gemini-3-pro-image`（Nano Banana Pro）   | 不可用   | 1K/2K 约 0.134 美元/张；4K 约 0.24 美元/张                                  |
| `gemini-3.1-flash-image`（Nano Banana 2） | 不可用   | 0.5K 约 0.045 美元、1K 约 0.067 美元、2K 约 0.101 美元、4K 约 0.151 美元/张 |

这些是带日期的美元价格，不是永久承诺，也没有包含汇率、税费、失败重试和为得到合格成品所需的多次迭代。做预算时应按“预计尝试次数 × 目标分辨率价格”计算，而不是只算最终采用的那一张。

如果只是偶尔修改一张公开图片，API 的接入成本可能没有必要；如果要批量处理商品图、记录每次请求、固定输出规格或接入应用，官方 API 的可追踪性通常比不透明积分更重要。

## 第三方积分：先得到分母，再计算图片数

第三方页面可能写注册赠送、每日签到、邀请奖励或订阅积分。它们都只能在该平台自己的合同里解释。一个大余额如果没有对应的单次扣费，仍然不能回答“能编辑几张”。

<img src="/docs/blog/zh/nano-banana-pro-image-to-image-free/img/image-workflow.webp" class="blog-content-image cursor-zoom-in transition-opacity group-hover:opacity-90" loading="lazy" alt="把可用积分、模型分辨率和单次扣分换算为编辑次数的流程图，缺少单次成本时输出未知" />

只有所有输入都来自同一平台、同一账号会话、同一模型、同一分辨率和同一编辑模式时，才使用：

`可编辑次数 = floor(可用积分 / 单次编辑积分)`

例如，某个虚构平台明确显示当前有 30 个可用积分，所选上传编辑模式在当前分辨率下每次扣 4 分，那么可以预算 `floor(30 / 4) = 7` 次，并剩余 2 分。这只是算术示例，不代表任何真实平台。

如果页面只写“登录后送 10 分”，却没有说明上传编辑每次扣多少，答案就是“可编辑次数未知”，而不是 10 张。若单次扣费写成 1–3 分，也要先确定当前模型、分辨率和编辑模式落在哪一档，才能得到一个可靠结果。

## 第三方页面的八项责任不能借给 Google

第三方站写着“官方模型”“每日积分”或“商用”，这些词也必须由该站的当前条款支持。模型身份、积分发放、重置时间、上传处理、输出授权、水印、客服和失败扣费，是八个不同字段；某一项清楚，不代表其他七项也清楚。

截至本文核验日期，我们没有为第三方示例创建账号，也没有验证登录后的真实余额、后端模型、图片删除行为、隐私处理、输出授权效力或失败退款。页面上的积分宣传只能作为平台自己的公开声明，不能证明 Google 为该账号发放了配额。

判断第三方是否值得用一张公开样图试跑，可以问：

1.  模型 ID 或模型来源是否在当前页面可验证，而不是只有产品名？
2.  积分是一次性赠送、自动恢复、手动签到、邀请奖励，还是付费余额？
3.  上传参考图是否比纯文字生图多扣分？高分辨率是否另收费？
4.  重置时间、时区、过期和结转是否写清楚？
5.  审核拦截、超时或生成失败是否退还？
6.  上传图片保留多久，能否删除，会不会用于其他目的？
7.  输出授权、水印和客服入口是否适用于当前免费或试用计划？

缺失的字段就写“未知”。营销页没有回答，不要从别的平台条款、营销摘要或旧教程里补一个看似合理的答案。

## 失败和限额用尽后，不要立即换站上传真实图

当页面提示限额用尽，先判断是哪条路线结束了：

-   **Gemini 账号限额结束：** 查看页面给出的恢复时间、模型切换或升级选项。不要把另一个账号或旧教程的数字当成当前恢复承诺。
-   **官方 API 请求失败：** 查看状态码、账单和请求日志，区分内容拒绝、超时、速率限制和已产生输出成本的重试。
-   **第三方积分不足或任务失败：** 先查失败是否扣分、积分何时恢复，再决定是否购买或退出。规则不清时，不要把剩余积分全部预算掉。

更换平台只会更换合同，不会自动解决隐私、授权或模型身份问题。尤其是客户照片、内部设计稿和未发布商品图，不应因为一个免费入口失效，就立刻上传到条款更少的另一个站。

## 常见问题

### Nano Banana Pro 免费额度到底是多少？

没有一个可以跨 Gemini、官方 API 和第三方编辑器通用的固定数字。Gemini 消费端看当前账号与页面提示；Pro 重做依赖符合条件的付费方案和当前用量；第三方积分只按该平台自己的合同解释。

### Gemini Pro 每天能生成或编辑多少张图？

不要用旧教程里的固定张数替代当前账号。Google 的中文帮助说明用量会受到模型、功能、提示复杂度、对话长度和计划等因素影响。打开当前 Gemini 页面查看模型、剩余用量和恢复提示，才是对该账号有效的答案。

### 创建 Gemini API key 会送免费图片额度吗？

不会。API key 是调用凭证。2026 年 7 月 17 日核验的官方价格页中，`gemini-3-pro-image` 和 `gemini-3.1-flash-image` 的图片标准层级均没有免费层级。

### 第三方每日签到积分是 Google 官方额度吗？

不是。签到、注册赠送、邀请奖励和平台订阅余额由第三方自己发放。它们不能转入 Gemini 账号或官方 API，也不能证明后端一定是 Nano Banana Pro。

### 第三方积分怎么换算成可编辑图片数？

只有在同一会话中明确可用积分和当前编辑模式的单次扣分时，才能使用 `floor(可用积分 / 单次编辑积分)`。模型、分辨率、编辑模式或分母缺失时，答案应保持“未知”。

### 可以上传客户照片或未发布产品图吗？

在保留、删除、训练使用、输出授权、支持渠道和适用合同未确认前，不要上传。先用公开或合成样图验证流程；真实素材应进入经过组织或权利人批准的路线。

### 额度用完后应该等待、换路线还是付费？

先看额度属于谁，以及页面给出的恢复规则。一次性任务可以等待或换用当前账号允许的模型；需要稳定交付、自动化、固定分辨率、日志或支持时，付费官方或合同明确的路线更可解释。不要为了绕过限额，把敏感图片上传到更不透明的平台。
