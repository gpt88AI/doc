एउटा तस्बिरको अंग्रेजीलाई स्पेनीमा बदल्न धेरै apps डाउनलोड गर्नु पहिलो कदम होइन; सही route छान्नुहोस्। एउटै फोटोका लागि फोनमा Google Translate camera/gallery वा computer मा web image mode बाट सुरु गर्नुहोस्। OCR कमजोर भए crop, प्रकाश र angle सुधार्नुहोस्; दैनिक batch, offline pack वा history चाहिँदा मात्र dedicated app मूल्याङ्कन गर्नुहोस्।

| अवस्था | पहिले प्रयोग गर्ने route | असफल भएपछि पहिलो कदम |
| --- | --- | --- |
| Menu, sign, label वा कागज अगाडि छ | Google Translate camera | नजिक जानुहोस्, glare हटाउनुहोस्, अंग्रेजी भाग मात्र छान्नुहोस् |
| Screenshot वा file computer मा छ | Web image mode | upload/layout असजिलो भए web OCR |
| Spanish स्पष्ट रूपमा गलत छ | पहिले image सुधार्नुहोस् | crop, straighten, light र English→Spanish फेरि जाँच्नुहोस् |
| दैनिक धेरै तस्बिर | Dedicated app मूल्याङ्कन | ads, subscription, security, deletion जाँच्नुहोस् |
| निजी जानकारी छ | पहिले crop/redact | आवश्यक text मात्र upload वा manually type गर्नुहोस् |

## Phone photo मा language direction पहिले मिलाउनुहोस्

Source English र target Spanish manually सेट गर्नुहोस्। साना शब्द, brand name वा mixed label हुँदा auto-detection गलत हुन सक्छ। Text ठूलो राख्नुहोस्, फोन सीधा राख्नुहोस्, glare/shadow/backlight हटाउनुहोस् र पूरा poster होइन आवश्यक sentence मात्र छान्नुहोस्। Gallery को original import गर्नुहोस्; screen पुनः खिच्दा blur, moiré र angle distortion बढ्छ। Offline अघि English र Spanish packs download गरी non-sensitive image मा test गर्नुहोस्।

## Computer screenshot मा web image mode

Digital screenshot, scan, product image वा manual लाई फोनले फेरि photograph नगर्नुहोस्। सफा single-page layout मा web image mode उपयोगी हुन्छ। Columns, tables, handwriting, rotated text वा सानो अक्षर भए paragraph/column छुट्टाछुट्टै crop गर्नुहोस्। Backup OCR लाई बढी accurate, private वा unlimited नमान्नुहोस्। Original image, recognized English र final Spanish सँगै राख्नुहोस्।

## OCR खराब भए tool बदल्नुअघि image सुधार्नुहोस्

Missing text भए crop सानो तर पूरा sentence राख्नुहोस्; wrong letters भए blur, glare र tilt सुधार्नुहोस्; merged columns अलग गर्नुहोस्; handwriting मा सबैभन्दा स्पष्ट line मात्र crop गर्नुहोस्। Number, date, unit, dosage र proper noun लाई original सँग मिलाउनुहोस्। `must`, `not`, `unless`, `before` गलत पढिए obligation नै उल्टिन सक्छ।

## Dedicated app कहिले उपयोगी हुन्छ

नियमित काममा offline packs, history, batch र copy management ले समय बचाउन सक्छ। Install अघि ads, trial/auto-renewal, cloud upload, retention, deletion, offline camera/gallery support र update हेर्नुहोस्। Clear sign, screenshot, non-sensitive invoice crop, low-light photo र multi-column text मा 3–5 test गर्नुहोस्। Download count वा “100+ languages” ले accuracy प्रमाणित गर्दैन।

## Private image पहिले सुरक्षित गर्नुहोस्

ID, invoice, medical record, contract, client screenshot, school file, address र QR code पूरा upload नगर्नुहोस्। आवश्यक English मात्र crop गरी नाम, account, face, barcode, amount र file number redact गर्नुहोस्। Context हराए key sentence manually type गर्नुहोस्। Legal, medical, financial र school सामग्रीमा machine translation draft मात्र हो, direct submission होइन।

## FAQ

### पहिले कुन tool?

एकल image का लागि Google Translate; फोनमा camera/gallery र computer मा web image mode।

### यो free हो?

Basic one-off translation प्रायः free हुन्छ, तर ads, offline, batch, export र advanced OCR मा सीमा हुन सक्छ।

### Google Translate ले तस्वीरमा English चिन्छ?

हो; mobile camera/gallery र web image upload दुवै entry point हुन्। English→Spanish manually सेट गर्नुहोस्।

### Recognized English गलत भए?

पहिले crop, angle, light र glare सुधार्नुहोस्। OCR layer गलत भए Spanish पनि अविश्वसनीय हुन्छ।

### Google Translate कि Yandex OCR?

Google बाट सुरु गर्नुहोस्; upload वा layout असजिलो भए दोस्रो OCR route लिनुहोस्। Spanish कति स्वाभाविक छ भन्दा recognized English सही छ कि छैन हेर्नुहोस्।

### Photo-translation app सुरक्षित हुन्छ?

आफैं सुरक्षित छ नमान्नुहोस्। Privacy policy पढ्नुहोस् र sensitive image crop/redact गर्नुहोस्।

### Internet बिना चल्छ?

केही apps language pack पछि offline camera दिन्छन्; पहिले non-sensitive image मा परीक्षण गर्नुहोस्।

### Handwritten English?

कहिलेकाहीँ सम्भव हुन्छ, तर print भन्दा कम स्थिर हुन्छ। स्पष्ट एक line crop गर्नुहोस्; गलत भए manually type गर्नुहोस्।
