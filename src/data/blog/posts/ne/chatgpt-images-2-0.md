Official ChatGPT खोल्नुहोस् र conversation मा image request लेख्नुहोस्, वा More menu बाट Images खोल्नुहोस्। Prompt मा purpose, subject, scene, composition, aspect ratio, आवश्यक text र unchanged items लेख्नुहोस्। Generate भएपछि तुरुन्त publish नगर्नुहोस्; zoom गरेर हेर्नुहोस्, एक वा दुई defect मात्र सुधार्नुहोस्, Save गरेर local file verify गर्नुहोस्।

UI names, quotas र Images with thinking को availability device, plan, region, rollout र account state अनुसार बदलिन सक्छ। Fixed images-per-day संख्या आफ्नो account message भन्दा माथि नराख्नुहोस्।

## Official ChatGPT पुष्टि गर्नुहोस्

Third-party page का नाम मिल्न सक्छन्, तर model, privacy, upload rules, rights र limits फरक हुन्छन्। Account, plan, image mode र limit message को retry time हेर्नुहोस्। Free user image quota API credit होइन।

## सात चरणको workflow

1. Delivery condition लेख्नुहोस्: channel, audience, subject, orientation, crop र गलत हुन नहुने text/facts।
2. Natural paragraph prompt दिनुहोस्: purpose + subject + scene + composition + aspect ratio + style + required text + forbidden changes।
3. Complex request लाई समय दिनुहोस्; बारम्बार submit नगर्नुहोस्।
4. Thumbnail होइन, full image zoom गरी subject, hands, faces, logos, text, numbers, dates र crop जाँच्नुहोस्।
5. एकपटकमा एक वा दुई variables मात्र बदल्नुहोस् र keep list लेख्नुहोस्।
6. Text-heavy poster मा सुन्दरभन्दा सहीलाई प्राथमिकता दिनुहोस्; price, date, medical/legal text र specs source बाट verify गर्नुहोस्।
7. Save पछि format, aspect ratio, version, filename र target page crop जाँच्नुहोस्।

## Uploaded image editing

आफ्नो वा licensed asset मात्र upload गर्नुहोस्। ID, credentials, private chats, confidential business material वा intimate image consent बिना upload नगर्नुहोस्। Whole-image editing lighting/background का लागि; region editing object वा local text का लागि हो। Selection सधैं precise नहुन सक्छ, त्यसैले प्रत्येक edit पछि पूरा image हेर्नुहोस्।

## Pre-publish check

Thumbnail मा topic स्पष्ट छ? Text character-by-character सही छ? Logo, quote, map, statistic वा product spec बनाइएको छैन? Asset licensed छ? Real-person likeness का लागि consent छ? Downloaded file खुल्छ र crop ठीक छ? स्पष्ट नभए publish नगर्नुहोस्।

## C2PA र SynthID

ChatGPT, Codex र OpenAI API images मा C2PA metadata र SynthID watermark हुन सक्छ। ती provenance clues हुन्, accuracy वा legal ownership certificate होइनन्। Prompts, licenses, source facts, edits र approval history record गर्नुहोस्; provenance marker हटाउने अभ्यास नगर्नुहोस्।

## ChatGPT र API फरक contracts

App experience र personal quota, API key, billing, errors, retries, storage, rate limits र permissions अलग छन्। App मा image बन्नु free `gpt-image-2` API access को प्रमाण होइन। Automation वा Batch का लागि API documentation हेर्नुहोस्।
