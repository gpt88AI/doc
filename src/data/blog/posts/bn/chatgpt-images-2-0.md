Official ChatGPT খুলে conversation-এ image request লিখুন, অথবা More menu থেকে Images খুলুন। Prompt-এ purpose, subject, scene, composition, aspect ratio, প্রয়োজনীয় text এবং unchanged items লিখুন। Generate হওয়ার পরে সঙ্গে সঙ্গে publish করবেন না: zoom করে দেখুন, এক বা দুইটি defect ঠিক করুন, Save করুন এবং local file যাচাই করুন।

UI name, quota এবং Images with thinking device, plan, region, rollout ও account state অনুযায়ী বদলাতে পারে। Fixed images-per-day সংখ্যাকে আপনার account-এর বর্তমান message-এর চেয়ে বেশি বিশ্বাস করবেন না।

## Official ChatGPT নিশ্চিত করুন

Third-party page-এর নাম একই হতে পারে, কিন্তু model, privacy, upload rule, rights ও limit আলাদা। Account ও plan দেখুন, image mode কী আছে দেখুন এবং limit message-এর retry time লিখে রাখুন। Free user-এর image quota API credit নয়।

## সাত ধাপের workflow

1. Delivery condition লিখুন: channel, audience, subject, orientation, crop এবং ভুল হওয়া চলবে না এমন text/facts।
2. Natural paragraph prompt দিন: purpose + subject + scene + composition + aspect ratio + style + required text + forbidden changes।
3. Complex request-কে সময় দিন; বারবার submit করলে request ও quota বোঝা কঠিন হয়।
4. Thumbnail নয়, full image zoom করুন: subject, hands, faces, logos, text, numbers, dates ও crop যাচাই করুন।
5. একবারে এক বা দুইটি variable বদলান এবং keep list লিখুন।
6. Text-heavy poster-এ সুন্দর দেখানোর আগে সঠিকতা যাচাই করুন; price, date, medical/legal text ও specs source দিয়ে মিলিয়ে নিন।
7. Save-এর পরে file format, aspect ratio, version, filename এবং target page-এর crop পরীক্ষা করুন।

## Uploaded image editing

নিজের বা licensed asset upload করুন। ID, credential, private chat, confidential business file বা intimate image consent ছাড়া upload করবেন না। Whole-image edit lighting ও background-এর জন্য; region edit object বা local text-এর জন্য। Selection পুরোপুরি precise নাও হতে পারে, তাই প্রতিটি edit-এর পরে পুরো image দেখুন।

## Pre-publish check

Thumbnail-এ topic স্পষ্ট? Text character-by-character ঠিক? Logo, quote, map, statistic বা product spec বানানো হয়নি? Asset licensed? Real-person likeness-এ consent আছে? Downloaded file খোলে এবং target channel crop করে না? উত্তর স্পষ্ট না হলে publish করবেন না।

## C2PA ও SynthID

ChatGPT, Codex এবং OpenAI API image-এ C2PA metadata ও SynthID watermark থাকতে পারে। এগুলি provenance clue, accuracy বা legal ownership certificate নয়। Prompt, license, source fact, edit এবং approval history নিজের record-এ রাখুন।

## ChatGPT ও API আলাদা contract

ChatGPT app-এর experience ও personal quota এবং API-এর key, billing, errors, retries, storage, limits ও permissions আলাদা। App-এ image তৈরি হওয়া free `gpt-image-2` API access প্রমাণ করে না। Automation বা Batch চাইলে API documentation অনুসরণ করুন।
