ছবির ইংরেজি স্প্যানিশে বদলানোর প্রথম কাজ অনেক translation app নামানো নয়; সঠিক route বেছে নেওয়া। একক ছবিতে ফোনের Google Translate camera/gallery বা কম্পিউটারের web image mode দিয়ে শুরু করুন। OCR ভুল হলে crop, আলো ও angle ঠিক করুন; নিয়মিত batch, offline pack বা history দরকার হলে dedicated app যাচাই করুন।

| পরিস্থিতি | প্রথম route | ব্যর্থ হলে প্রথম পদক্ষেপ |
| --- | --- | --- |
| Menu, sign, label বা কাগজ সামনে | Google Translate camera | কাছে যান, glare কমান, শুধু ইংরেজি অংশ নিন |
| Screenshot বা file কম্পিউটারে | Web image mode | upload/layout সমস্যা হলে web OCR |
| Spanish স্পষ্টত ভুল | আগে image ঠিক করুন | crop, straighten, light ও English→Spanish পুনরায় দেখুন |
| প্রতিদিন অনেক ছবি | Dedicated app evaluate | ads, subscription, security, deletion দেখুন |
| Private data আছে | আগে crop/redact | শুধু দরকারি text upload বা manually type |

## ফোনের ছবিতে language direction ঠিক করুন

Source English এবং target Spanish manually সেট করুন। ছোট শব্দ, brand name বা mixed label-এ auto-detection ভুল হতে পারে। Text বড় করে ধরুন, ফোন সোজা রাখুন, glare/shadow/backlight এড়ান এবং পুরো poster নয়, প্রয়োজনীয় sentence নির্বাচন করুন। Gallery-তে original import করুন; screen পুনরায় photograph করলে blur, moiré ও angle distortion বাড়ে। Offline ব্যবহারের আগে English ও Spanish pack download করে non-sensitive image test করুন।

## কম্পিউটার screenshot-এ web image mode

Digital screenshot, scan, product image বা manual-কে ফোন দিয়ে আবার তুলবেন না। পরিষ্কার single-page layout-এ web image mode কার্যকর। Column, table, handwriting, rotated text বা ছোট font হলে paragraph/column আলাদা crop করুন। Backup OCR-কে বেশি accurate, private বা unlimited ধরে নেবেন না। Original image, recognized English এবং final Spanish একসঙ্গে রাখুন।

## OCR খারাপ হলে আগে image ঠিক করুন

Missing text হলে crop ছোট করুন কিন্তু পুরো sentence রাখুন; wrong letter হলে blur, glare ও tilt ঠিক করুন; merged column আলাদা করুন; handwriting-এর সবচেয়ে পরিষ্কার line crop করুন। Number, date, unit, dosage ও proper noun original-এর সঙ্গে মিলিয়ে দেখুন। `must`, `not`, `unless`, `before` ভুল পড়লে Spanish obligation উল্টে যেতে পারে।

## Dedicated app কখন মূল্যবান

নিয়মিত কাজে offline pack, history, batch ও copy management সময় বাঁচাতে পারে। Install-এর আগে ads, trial/auto-renewal, cloud upload, retention, deletion, offline support এবং updates দেখুন। Clear sign, screenshot, non-sensitive invoice crop, low-light photo ও multi-column text দিয়ে 3–5টি test করুন। Download count বা “100+ languages” accuracy প্রমাণ করে না।

## Private image আগে সুরক্ষিত করুন

ID, invoice, medical record, contract, client screenshot, school file, address ও QR code পুরোটা upload করবেন না। শুধু দরকারি English crop করে name, account, face, barcode, amount ও file number redact করুন। Context নষ্ট হলে key sentence manually type করুন। Legal, medical, financial ও school content-এ machine translation শুধু draft, সরাসরি submission নয়।

## FAQ

### কোন tool আগে?

একটি ছবিতে Google Translate; ফোনে camera/gallery, কম্পিউটারে web image mode।

### এটি কি free?

Basic one-off অনুবাদ প্রায়ই free, কিন্তু ads, offline, batch, export ও advanced OCR সীমিত হতে পারে।

### Google Translate কি ছবির English চিনতে পারে?

হ্যাঁ; mobile camera/gallery এবং web image upload ব্যবহার করা যায়। English→Spanish manually সেট করুন।

### Recognized English ভুল হলে?

আগে crop, angle, আলো ও glare ঠিক করুন। OCR ভুল হলে Spanish-ও নির্ভরযোগ্য নয়।

### Google Translate না Yandex OCR?

Google দিয়ে শুরু করুন; upload awkward বা layout complex হলে দ্বিতীয় OCR route নিন। Spanish মসৃণ কিনা নয়, English recognition ঠিক কিনা দেখুন।

### Photo-translation app নিরাপদ?

ধরে নেবেন না। Privacy policy দেখুন এবং sensitive image crop/redact করুন।

### Internet ছাড়া চলে?

কিছু app language pack-এর পরে offline camera দেয়; আগে non-sensitive test করুন।

### Handwritten English?

সম্ভব, তবে কম স্থির। পরিষ্কার এক line crop করুন; ভুল হলে manually type করুন।
