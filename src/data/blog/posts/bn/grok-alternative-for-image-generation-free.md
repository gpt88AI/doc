Grok Imagine unavailable বা quota শেষ হলে “unlimited Grok” wrapper না খুঁজে পরিষ্কার contract-এর route নিন। Mainland China-তে আগে Qwen Studio পরীক্ষা করুন; private assets, batch এবং reusable workflow-এর জন্য Qwen-Image + ComfyUI local route; supported Adobe account থাকলে Firefly-কে conditional option হিসেবে দেখুন।

## Route Table

| কাজ | আগে test করুন | Free-এর বাস্তব অর্থ |
| --- | --- | --- |
| Chinese poster/illustration | Qwen Studio | free entry, fixed permanent count নয় |
| Editing/repeated composition | Qwen Studio বা local Qwen-Image | online quota বা local compute |
| Private batch/workflow | Qwen-Image + ComfyUI | platform quota নেই, hardware/maintenance cost আছে |
| Commercial Adobe work | supported account-এ Firefly | limited free generations, model/rights যাচাই |
| Icons/vector concepts | Recraft Free, personal use | public output, commercial use নয় |

Microsoft-এর current availability China-কে Bing Image Creator থেকে বাদ দেয় এবং OpenAI supported-country list-এ mainland China নেই। Shared account, VPN/region bypass, borrowed identity বা copied key availability প্রমাণ করে না।

## Qwen Studio ছোট Test

1:1 Chinese poster তৈরি করুন, আটটির বেশি character নয়; দ্বিতীয় round-এ শুধু একটি শব্দ বদলান। Title accuracy, date, extra text, composition stability, download এবং edit entry পরীক্ষা করুন। “Free to use” unlimited বা queue-free নয়; নিজের account-এর limit record করুন।

## Local Qwen-Image + ComfyUI

Local route privacy, repeatability এবং parameter control দেয়, zero cost নয়। Hardware/VRAM, model license/hash, custom-node source, network, logs এবং save path যাচাই করুন। Fictional sample-এ seed fix করে তিনটি background variant বানিয়ে workflow JSON save করুন এবং restart-এর পর reproduce করুন।

## Firefly, Recraft ও Wrappers

Firefly-তে model, beta state, plan, date, credits এবং commercial terms লিখে রাখুন। Recraft Free output public ও non-commercial; client logo বা NDA material দেবেন না। “Free/unlimited/no login” page-এ operator, data recipient, quota, visibility, rights এবং deletion স্পষ্ট না হলে upload করবেন না। Real face, child, ID বা client asset-এর বদলে fictional sample ব্যবহার করুন।

দুই candidate-কে একই aspect ratio, Chinese title, subjects এবং forbidden items দিন। Round 1 generate, Round 2-এ একটি variable edit; Chinese accuracy, instruction retention, current usability, rights clarity এবং data risk-এ 0-2 score দিন। 7-এর নিচে হলে route বদলান; rights বা data risk 0 হলে commercial/private use বাদ দিন।

Ordinary Chinese image-এর জন্য Qwen Studio, private/batch-এর জন্য Qwen-Image + ComfyUI এবং supported Adobe account-এ Firefly দেখুন। Universal winner নেই। Grok বা Qwen unlimited free নয়; current quota, queue, model ও feature state যাচাই করুন। Local deployment-এ hardware, electricity, download, setup, maintenance ও storage cost থাকে।
