## 阅读建议

- 先确认需求、预算、稳定性和可用模型范围，再比较具体方案。
- 涉及密钥、额度或账单的操作，应先用低风险请求验证，再逐步扩大使用量。
- 不要只看单次价格；稳定性、支持响应和异常处理同样会影响长期成本。
