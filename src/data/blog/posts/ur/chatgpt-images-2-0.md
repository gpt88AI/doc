Official ChatGPT کھولیں اور conversation میں image request لکھیں، یا More menu سے Images کھولیں۔ Prompt میں purpose، subject، scene، composition، aspect ratio، مطلوبہ text اور unchanged items لکھیں۔ Generate کے فوراً بعد publish نہ کریں؛ zoom کریں، ایک یا دو defects درست کریں، Save کریں اور local file verify کریں۔

UI names، quotas اور Images with thinking کی availability device، plan، region، rollout اور account state کے ساتھ بدل سکتی ہے۔ Fixed images-per-day تعداد کو اپنے account کے موجودہ message سے اوپر نہ رکھیں۔

## Official ChatGPT کی تصدیق

Third-party صفحات کا نام ایک جیسا ہو سکتا ہے، مگر model، privacy، upload rules، rights اور limits مختلف ہو سکتے ہیں۔ Account اور plan دیکھیں، available image mode نوٹ کریں اور limit message کا retry time محفوظ کریں۔ Free user image quota API credit نہیں۔

## سات قدم کا workflow

1. Delivery conditions لکھیں: channel، audience، subject، orientation، crop اور لازم درست text/facts۔
2. Natural paragraph prompt دیں: purpose + subject + scene + composition + aspect ratio + style + required text + forbidden changes۔
3. Complex request کو وقت دیں؛ بار بار submit کرنے سے request اور quota مبہم ہوتے ہیں۔
4. Thumbnail نہیں، full image zoom کریں: subject، hands، faces، logos، text، numbers، dates اور crop دیکھیں۔
5. ایک وقت میں ایک یا دو variables بدلیں اور keep list لکھیں۔
6. Text-heavy poster میں خوب صورتی سے پہلے درستگی رکھیں؛ prices، dates، medical/legal text اور specs کو source سے ملائیں۔
7. Save کے بعد format، aspect ratio، version، filename اور target page crop verify کریں۔

## Uploaded image editing

صرف اپنا یا licensed asset upload کریں۔ IDs، credentials، private chats، confidential business material یا intimate images بغیر consent نہ دیں۔ Whole-image editing lighting، tone اور background کے لیے؛ region editing object یا local text کے لیے ہے۔ Selection مکمل precise نہیں ہو سکتی، اس لیے ہر edit کے بعد پورا image دیکھیں۔

## Pre-publish check

کیا thumbnail میں topic واضح ہے؟ Text character-by-character درست ہے؟ Logo، quote، map، statistic یا product spec گھڑی نہیں گئی؟ Asset licensed ہے؟ Real-person likeness کے لیے consent ہے؟ Downloaded file کھلتی ہے اور crop درست ہے؟ جواب واضح نہ ہو تو publish نہ کریں۔

## C2PA اور SynthID

ChatGPT، Codex اور OpenAI API images میں C2PA metadata اور SynthID watermark ہو سکتے ہیں۔ یہ provenance clues ہیں، accuracy یا legal ownership certificate نہیں۔ Prompts، licenses، source facts، edits اور approval history اپنے records میں رکھیں؛ provenance markers ہٹانے کی کوشش نہ کریں۔

## ChatGPT اور API الگ contracts

App experience اور personal quota، API key، billing، errors، retries، storage، rate limits اور permissions سے الگ ہیں۔ App میں image بننا free `gpt-image-2` API access ثابت نہیں کرتا۔ Automation یا Batch کے لیے API documentation دیکھیں۔
