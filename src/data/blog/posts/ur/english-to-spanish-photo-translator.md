ایک تصویر میں انگریزی کو ہسپانوی میں بدلنے کا پہلا قدم بہت سی apps ڈاؤن لوڈ کرنا نہیں بلکہ درست route چننا ہے۔ ایک تصویر کے لیے فون پر Google Translate camera/gallery یا کمپیوٹر پر web image mode سے شروع کریں۔ OCR خراب ہو تو crop، روشنی اور angle درست کریں؛ روزانہ batch، offline packs یا history چاہیے تو dedicated app کا جائزہ لیں۔

| صورتِ حال | پہلا route | ناکامی کے بعد پہلا قدم |
| --- | --- | --- |
| Menu، sign، label یا کاغذ سامنے ہے | Google Translate camera | قریب جائیں، glare کم کریں، صرف انگریزی حصہ منتخب کریں |
| Screenshot یا file کمپیوٹر پر ہے | Web image mode | upload/layout مشکل ہو تو web OCR آزمائیں |
| Spanish واضح طور پر غلط ہے | پہلے تصویر درست کریں | crop، straighten، light اور English→Spanish دوبارہ چیک کریں |
| روز کئی تصاویر | Dedicated app کا جائزہ | ads، subscription، security اور deletion دیکھیں |
| نجی معلومات موجود ہیں | پہلے crop/redact | صرف ضروری text upload یا manually type کریں |

## فون کی تصویر میں language direction پہلے درست کریں

Source English اور target Spanish manually set کریں۔ چھوٹے الفاظ، brand names اور mixed labels میں auto-detection غلط ہو سکتا ہے۔ متن کو بڑا رکھیں، فون سیدھا رکھیں اور glare/shadow/backlight سے بچیں۔ پورا poster نہیں، صرف مطلوبہ جملہ منتخب کریں۔ Original gallery file import کریں؛ screen کو دوبارہ photograph کرنے سے blur، moiré اور angle distortion بڑھتے ہیں۔ Offline استعمال سے پہلے English اور Spanish language packs download کر کے non-sensitive image پر test کریں۔

## کمپیوٹر screenshot کے لیے web image mode

Digital screenshot، scan، product image یا manual کو فون سے دوبارہ نہ کھینچیں۔ صاف single-page layout میں web image mode بہتر ہے۔ Columns، tables، handwriting، rotated text یا چھوٹے حروف ہوں تو paragraph/column الگ crop کریں۔ Backup OCR کو زیادہ accurate، private یا unlimited نہ سمجھیں۔ Original image، recognized English اور final Spanish ساتھ محفوظ رکھیں۔

## OCR خراب ہو تو پہلے تصویر درست کریں

Missing text پر crop چھوٹا کریں مگر پورا sentence رکھیں؛ غلط حروف پر blur، glare اور tilt درست کریں؛ merged columns الگ کریں؛ handwriting کی صاف line crop کریں۔ Numbers، dates، units، dosages اور proper nouns کو اصل تصویر سے ملائیں۔ `must`، `not`، `unless` اور `before` غلط پہچانے جائیں تو obligation الٹ سکتی ہے۔

## Dedicated app کب نصب کریں

بار بار کام میں offline packs، history، batch اور copy management وقت بچاتے ہیں۔ Install سے پہلے ads، trial/auto-renewal، cloud upload، retention، deletion، offline camera/gallery support اور updates دیکھیں۔ Clear sign، screenshot، non-sensitive invoice crop، low-light photo اور multi-column text سے 3–5 tests کریں۔ Download count یا “100+ languages” accuracy کا ثبوت نہیں۔

## نجی تصاویر پہلے محفوظ کریں

IDs، invoices، medical records، contracts، client screenshots، school files، addresses اور QR codes پوری طرح upload نہ کریں۔ ضروری English crop کریں اور نام، account، face، barcode، amount اور file number redact کریں۔ Context ختم ہو تو key sentences manually type کریں۔ Legal، medical، financial اور school مواد میں machine translation صرف draft ہے، submission یا payment evidence نہیں۔

## FAQ

### پہلے کون سا tool؟

ایک تصویر کے لیے Google Translate؛ فون پر camera/gallery اور کمپیوٹر پر web image mode۔

### کیا یہ free ہے؟

Basic one-off translation اکثر free ہوتی ہے، مگر ads، offline، batch، export اور advanced OCR محدود ہو سکتے ہیں۔

### کیا Google Translate تصویر میں English پہچانتا ہے؟

ہاں، mobile camera/gallery اور web image upload دونوں entry points ہیں۔ English→Spanish manually set کریں۔

### Recognized English غلط ہو تو؟

پہلے crop، angle، روشنی اور glare درست کریں۔ OCR layer غلط ہو تو Spanish بھی غیر معتبر ہوگی۔

### Google Translate یا Yandex OCR؟

Google سے شروع کریں؛ upload یا layout مشکل ہو تو دوسرا OCR route لیں۔ Smooth Spanish کے بجائے recognized English کی صحت دیکھیں۔

### کیا photo-translation apps محفوظ ہیں؟

Default طور پر نہ سمجھیں۔ Privacy policy پڑھیں اور حساس تصویر crop/redact کریں۔

### کیا internet کے بغیر چلتا ہے؟

کچھ apps language packs کے بعد offline camera دیتی ہیں؛ پہلے non-sensitive test کریں۔

### Handwritten English؟

ممکن ہے مگر کم stable۔ صاف ایک line crop کریں، غلط ہو تو manually type کریں۔
