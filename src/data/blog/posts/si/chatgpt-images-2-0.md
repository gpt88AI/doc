## පියවර හතේ workflow

1. Delivery conditions ලියන්න: channel, audience, subject, orientation, crop සහ වැරදි නොවිය යුතු text/facts।
2. Natural paragraph prompt එකක් දෙන්න: purpose + subject + scene + composition + aspect ratio + style + required text + forbidden changes.
3. Complex request එකට කාලය දෙන්න; නැවත නැවත submit නොකරන්න.
4. Thumbnail එකක් නොව full image එක zoom කර subject, hands, faces, logos, text, numbers, dates සහ crop පරීක්ෂා කරන්න.
5. එකවර variables එකක් හෝ දෙකක් පමණක් වෙනස් කර keep list එකක් ලියන්න.
6. Text-heavy poster එකක ලස්සනට වඩා නිවැරදි බවට ප්‍රමුඛත්වය දෙන්න; price, date, medical/legal text සහ specs source සමඟ verify කරන්න.
7. Save පසු format, aspect ratio, version, filename සහ target page crop පරීක්ෂා කරන්න.
