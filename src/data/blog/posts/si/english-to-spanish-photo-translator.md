## Phone photo එකේ language direction මුලින් සකසන්න

Source English සහ target Spanish manually set කරන්න. කුඩා වචන, brand names හෝ mixed labels ඇතිවිට auto-detection වැරදිය හැක. Text එක විශාලව තබා phone එක සෘජුව තබන්න; glare, shadow සහ backlight වළක්වන්න. සම්පූර්ණ poster එක වෙනුවට අවශ්‍ය sentence එක පමණක් තෝරන්න. Gallery එකේ original file එක import කරන්න; screen එක නැවත photograph කළහොත් blur, moiré සහ angle distortion වැඩි වේ. Offline භාවිතයට පෙර English සහ Spanish packs download කර non-sensitive image එකකින් test කරන්න.

## Computer screenshot සඳහා web image mode

Digital screenshot, scan, product image හෝ manual එක phone එකෙන් නැවත ඡායාරූපගත නොකරන්න. පැහැදිලි single-page layout සඳහා web image mode ගැළපේ. Columns, tables, handwriting, rotated text හෝ කුඩා අකුරු තිබේ නම් paragraph/column වෙන වෙනම crop කරන්න. Backup OCR එක වඩා accurate, private හෝ unlimited යැයි නොසිතන්න. Original image, recognized English සහ final Spanish එකට තබන්න.

## OCR දුර්වල නම් tool මාරු කිරීමට පෙර image එක සකස් කරන්න

Missing text නම් crop කුඩා කළත් සම්පූර්ණ sentence තබන්න; wrong letters නම් blur, glare සහ tilt සකස් කරන්න; merged columns වෙන් කරන්න; handwriting සඳහා පැහැදිලි line එකක් පමණක් crop කරන්න. Numbers, dates, units, dosage සහ proper nouns original එක සමඟ පරීක්ෂා කරන්න. `must`, `not`, `unless`, `before` වැරදිව හඳුනාගතහොත් obligation එක වෙනස් විය හැක.

## Dedicated app එකක් කවදා වටිනවාද

නිතර කරන වැඩ සඳහා offline packs, history, batch සහ copy management කාලය ඉතිරි කරයි. Install කිරීමට පෙර ads, trial/auto-renewal, cloud upload, retention, deletion, offline camera/gallery support සහ updates බලන්න. Clear sign, screenshot, non-sensitive invoice crop, low-light photo සහ multi-column text සමඟ 3–5 tests කරන්න. Download count හෝ “100+ languages” accuracy ඔප්පු නොකරයි.

## Private images මුලින් ආරක්ෂා කරන්න

IDs, invoices, medical records, contracts, client screenshots, school files, addresses සහ QR codes සම්පූර්ණයෙන් upload නොකරන්න. අවශ්‍ය English පමණක් crop කර name, account, face, barcode, amount සහ file number redact කරන්න. Context නැති වුවහොත් key sentences manually type කරන්න. Legal, medical, financial සහ school material සඳහා machine translation draft එකක් පමණි; direct submission නොවේ.

## FAQ

### මුලින් කුමන tool එකද?

එක් image එකකට Google Translate; phone එකේ camera/gallery සහ computer එකේ web image mode.

### මෙය free ද?

Basic one-off translation බොහෝවිට free ය, නමුත් ads, offline, batch, export සහ advanced OCR සඳහා සීමා තිබිය හැක.

### Google Translate රූපයක English හඳුනාගන්නවාද?

ඔව්; mobile camera/gallery සහ web image upload භාවිත කළ හැක. English→Spanish manually set කරන්න.

### Recognized English වැරදි නම්?

මුලින් crop, angle, light සහ glare සකස් කරන්න. OCR වැරදි නම් Spanish ප්‍රතිඵලයත් විශ්වාස කළ නොහැක.

### Google Translate ද Yandex OCR ද?

Google වලින් ආරම්භ කර upload හෝ layout අපහසු නම් දෙවන OCR route එකක් ගන්න. Spanish ස්වභාවිකද යන්නට වඩා English recognition නිවැරදිද බලන්න.

### Photo-translation apps ආරක්ෂිතද?

Default ලෙස ආරක්ෂිත යැයි නොසිතන්න. Privacy policy කියවා sensitive image crop/redact කරන්න.

### Internet නැතිව භාවිත කළ හැකිද?

සමහර apps language packs පසු offline camera දෙන නමුත් කලින් non-sensitive image එකක test කරන්න.

### Handwritten English?

සමහරවිට හැක, නමුත් print වලට වඩා අස්ථාවරය. පැහැදිලි line එකක් crop කර වැරදි නම් manually type කරන්න.
