AI 视频制作的难点不只是选一个视频模型。一个想法要变成完整成片，还要经过剧情、镜头、构图、角色一致性、首尾帧、运动提示、生成检查和后期剪辑。前面没有想清楚的问题，往往会在付费生成后才暴露，导致重复抽卡。

本文整理自 Eian 在 X 发布的长文[《Claude code/Codex+Seedance AI视频：从一个想法到成片的全流程》](https://x.com/i/article/2118298893238845441)，原帖见 [Eian 的分享](https://x.com/eianlu/status/2118317430665613741)。文章记录了作者自己的工具组合与制作经验。Seedance 版本、价格和产品能力会变化，文中涉及的省钱经验应结合当前套餐和实际镜头测试；这不是某一模型效果或价格的保证。

## 让每个模型负责擅长的环节

作者采用“一个导演入口，多个专门执行者”的方式：Claude Code 负责统筹、讨论故事和调用工具，Codex 负责生成或修改关键画面，Seedance 负责把静态首尾帧扩展成动态片段，FFmpeg 与 Python 则用于拼接、转场、调色、裁切和放大。作者也提到可以由 Codex 承担导演入口的工作。

这种分工的价值在于让创作者围绕故事和检查结果做决定，不必在每一步手工搬运上下文。它不意味着所有环节都应该全自动：剧情定稿、关键画面验收、付费视频提交和最终成片审核，仍然适合设置清晰的人类确认点。

可以把整条制作链看成：

```text
创意简报 → 故事定稿 → 分镜与视觉规范 → 首尾帧 → 视频生成 → 剪辑合成 → 全片复核
                    ↑                 ↑             ↑
                独立审稿          付费前检查      保留版本、复盘
```

## 第一步：先把想法写成能拍的故事

起点不必是完整剧本。先用几句话说明想表达什么、主角是谁、发生了什么，再与模型讨论并逐步收敛剧情。作者建议在进入画面制作前，至少检查以下几点：

- **现实逻辑**：每个转折都能解释原因、道具来源、人物位置和动作可达性。若有意采用超现实设定，则要让规则本身保持一致。
- **一句话主题**：能否说清这支片子想表达什么？如果主题和剧情都讲不明白，先继续改故事。
- **开场吸引力**：把最值得观看的冲突或画面尽早呈现，避免关键内容拖到片尾。
- **可信的反应**：每个转折按“问题出现、主角处理、旁人反应”的顺序设计，并给不同人物留出反应先后。
- **模型可执行性**：尽量少用人物交叉、细小物件操作、镜面反射、复杂群戏、连续多动作等容易造成画面不稳定的情节。

对生成视频来说，片段式故事通常更容易制作：每个镜头可以独立成立，不必依靠复杂的连续动作衔接。若必须使用连贯叙事，就要提前明确人物、道具和空间在相邻镜头里的位置变化。

故事初稿完成后，可以交给一个不了解创作过程的审稿 Agent，只看故事本身并指出看不懂的地方。主创和导演模型已经熟悉背景，容易替剧本补全没有写出的信息；冷读者更容易发现这些缺口。修改后再由创作者确认定稿。

## 第二步：用分镜把镜头语言说清楚

分镜不只是把剧情分成几格，还要说明观众会看到什么、镜头为什么移动，以及每个镜头如何接到下一个镜头。可以逐镜写明：

- 景别与机位，例如远景、半身、特写、俯拍、仰拍或过肩；
- 主体在画面中的位置，以及人物从画面左侧还是右侧移动；
- 摄影机是固定、跟随、推近还是拉远；
- 镜头中具体发生的动作或变化；
- 人物通过什么表情或动作推动情绪；
- 进入下一镜的转场方式。

原文建议用参考影片帮助模型理解镜头语言：让模型观察机位、景别、构图和主体在画面中的比例，再把这些信息转写为分镜。没有参考片时，也要避免连续多个镜头使用同样的正面视角和景别。

每个镜头最好都能回答“这一镜里什么在动”。可以是角色移动、摄影机运动、焦点变化、环境元素经过，也可以是很小的表情或手势。运动要有叙事目的；并非每一镜都要晃动，静与动的对比同样重要。作者还建议检查单帧构图，让视频暂停在任意一秒时画面仍然成立；黄金比例可以作为构图参考，但不必当成固定公式。

## 第三步：先确定画风和连续性规则

在生成镜头之前，先选定整片的视觉方向，例如手绘、水彩、剪纸、写实或特定的色彩气质。接着整理角色与关键道具的设定图，明确正面、侧面、表情、服饰和固定特征的位置。

角色一致性不应只依赖模型记忆。可以为每个角色维护一份简短视觉规范，写清发型、服装、颜色、标志性配件及不能改变的特征；固定道具也要描述形状、颜色和出现位置。每个场景再补充自己的配色与明暗对比，必要时检查黑白图，确认人物和背景没有糊在一起。

## 第四步：先做关键帧，再付费生成动态片段

作者把首尾帧视为降低返工的重要环节：先确定每个镜头开始时和结束时的画面，再让模型生成两者之间的运动。与只靠文字生成整段视频相比，关键帧能提前锁定角色、道具、构图和空间关系。

推荐顺序是先把镜头画面写成清单，说明首帧、尾帧和中间动作，再检查清单是否符合分镜和角色规范；审核通过后再出图。对同一地点、同一机位的连续镜头，可以在既有图片上修改，以减少构图漂移。需要推近的镜头，则要让首尾帧的取景范围有合理变化。

提交前还要检查：

- 首帧与尾帧的角色、服装、道具和空间关系是否一致；
- 需要持续出现的雨、帽子、纹身等细节是否在关键帧中明确可见；
- 左右方向、主体大小和镜头运动是否符合分镜；
- 图片比例和分辨率是否满足视频模型输入要求，两帧尺寸是否一致。

## 第五步：把视频提示写成可检查的动作时间线

原文建议使用固定的分段式提示词，并描述每一秒发生什么。重点不是提示词越长越好，而是把文字、关键帧和运动要求对齐：模型在什么时候移动什么主体、主体往哪个方向走、摄影机如何跟随，以及镜头在哪个状态结束。

下面是本文为方便执行整理的检查结构，不是对原文截图中提示词模板的逐字还原：

1. **镜头目标**：这一镜要传达什么信息或情绪。
2. **场景与连续性**：地点、人物、服装、道具和光线基准。
3. **构图与机位**：景别、视角、主体位置和画面方向。
4. **时间线动作**：按时间顺序描述主要动作及其先后。
5. **摄影机运动**：固定、跟拍、推拉或焦点变化，并说明运动目的。
6. **结束状态**：尾帧应呈现什么，如何为下一镜留出衔接。
7. **边界条件**：哪些特征必须保持、哪些变化不应发生，以及声音要求。

提示词写好后，让独立审稿 Agent 对照首尾帧逐项检查左右方向、物件数量、尺寸、服饰、动作顺序和画面连续性。原文举例说，审核可以发现杯子大小不一致、帽檐只出现在一帧、左右方向写反等问题。这类矛盾如果等视频生成后才发现，修复成本会高得多。

## 第六步：用小批量验证控制生成成本

生成视频通常比修改文本或静态图片更昂贵。原文的做法是先在文字和关键帧阶段尽可能发现错误，再把少量高风险镜头交给视频模型验证。另一种稳妥的执行方式是先挑一两个最难的镜头试跑；确认提示词、首尾帧和模型能力匹配后，再扩展到其他镜头。

可以考虑以下成本控制方法：

- 对简单镜头先测试较低分辨率，确认画面和运动可用后，再决定是否做高分辨率版本或后期放大；放大不能恢复原始细节，需检查人物、文字和边缘质量。
- 按镜头复杂度选择模型与时长，不要为每个镜头默认使用最高成本设置。模型价格、版本和生成效果会更新，提交前应重新核对当前产品页面与账户预算。
- 生成后先检查整段内容再决定是否重做。若问题只在片头片尾，可以剪裁；能通过代码或后期修好的，先评估修复成本。
- 每次重试都先改提示词或关键帧，并保留旧版本供比较；原样重复生成不一定能解决同一问题。
- 试听模型生成的音频。若不符合预期，可以去掉原音轨，再单独制作或添加声音。

调用付费 API 前，应由人确认模型、时长、分辨率和预算上限。API Key 不要写进文章、提示词或仓库，也不要让 Agent 自动充值；将凭据放在本地环境变量或受控的密钥管理工具中。

## 第七步：合成、剪辑并统一画面

当各个镜头都通过检查后，再进入全片剪辑。原文建议用 FFmpeg、Python 等工具处理片段拼接、转场、调色和放大。代码化的好处是参数可复用、改动可追踪，也便于重新输出不同版本。

自动化剪辑前先建立一份镜头清单：镜头编号、素材版本、时长、音轨、转场、裁切和色彩处理。剪辑输出后，检查时间线是否完整、音画是否同步、比例是否一致、转场是否突兀，以及放大后的细节是否劣化。不要只凭命令成功就认定成片已经可交付。

## 第八步：像观众一样复核并沉淀经验

成片完成后，可以交给一个独立审核 Agent，从头到尾观看，只报告问题，不替主创修改。审核最好对照创作简报和分镜，检查主题是否清楚、角色和道具是否连续、动作是否可信、节奏是否流畅、声音与画面是否协调。

最后，把采用的视觉规范、提示词版本、生成参数、失败原因、可复用的修复方法和最终选用素材记录下来。下次制作时，复用经过验证的经验，而不是依赖某个模型“记得上一次怎么做”。

## 四 Agent 分工：把创作、检查和预算分开

原文还介绍了四线程协作方式。可将它归纳为四个职责：

| 角色 | 工作范围 | 关键约束 |
| --- | --- | --- |
| 导演 / 主 Agent | 和创作者讨论故事，组织分镜、提示词、图像与后期工作 | 记录决定和当前素材版本 |
| 审核 Agent | 只检查当前阶段交付物并报告问题 | 不直接改文件；付费生成前需明确通过 |
| 要求监督 Agent | 对照项目简报检查每一步有没有漏掉要求 | 只读取本项目必要资料，避免无关个人记录 |
| 偏好与预算裁决 Agent | 在偏好或方案冲突时依据已确认的目标和预算给出建议 | 不得超预算批准；不执行充值或未经确认的付费调用 |

四个角色并不一定要由四个不同模型承担，重点是让检查职责独立于产出职责。开始制作前由创作者确认目标、素材来源、总预算和哪些环节必须人工批准；每次付费生成前记录价格估算与本次上限，达到预算就暂停，等待创作者决定后续安排。

交给 Agent 的素材也应遵循最小范围：只提供当前项目所需的故事、镜头表和资产，不必把完整个人聊天记录、客户机密或无关文件全部交给每个子 Agent。

## 一页式制作检查表

- [ ] 一句话创意、故事结构和结尾已确认。
- [ ] 剧情符合预期逻辑，AI 容易呈现的限制已纳入设计。
- [ ] 每个镜头都有景别、机位、画面方向、动作和转场。
- [ ] 角色、道具、色彩和画幅规范已经固定。
- [ ] 每个镜头的首尾帧已检查，关键视觉特征保持一致。
- [ ] 视频提示词与镜头表、关键帧一致，独立检查已完成。
- [ ] 已确认本次生成的模型、设置和预算，并由人批准。
- [ ] 失败版本被保留，重试前已修改提示词或画面。
- [ ] 合成后检查了画面、声音、节奏、比例和素材授权。
- [ ] 全片复核完成，制作记录和可复用经验已归档。

## 总结

这套流程的核心，是把昂贵的视频生成放在制作链的后段：先用文字明确故事，再用分镜约束镜头语言，用角色设定和首尾帧固定视觉信息，最后才提交视频生成。每一道检查都尽量把错误留在更便宜、更容易修改的阶段。

工具负责分工，Agent 负责起草与检查，创作者仍负责表达意图、审美选择和付费授权。通过可复核的阶段交付物、独立审稿和预算边界，AI 视频制作才能从反复抽卡变成一条更可控的生产流程。
