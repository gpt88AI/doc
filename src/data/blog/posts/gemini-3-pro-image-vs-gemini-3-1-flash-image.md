如果任务只需要快速筛选 1K 方向，先选 Nano Banana 2 Lite；需要 2K 或 4K、较多变体或更通用的图像生成与编辑时，先从 Nano Banana 2 开始；只有密集文字、复杂品牌规则、关键产品 mockup 或返工代价很高的交付，才应把 Nano Banana Pro 放入同输入对照。这里的结论是 API 路由判断，不等于 Gemini App、AI Studio、Vertex、地区套餐或第三方平台的价格与可用性。

三个当前模型 ID 分别是 `gemini-3.1-flash-lite-image`、`gemini-3.1-flash-image` 和 `gemini-3-pro-image`。它们没有一个是所有场景的总冠军；真正要比较的是：在相同输入和验收线下，哪条路线的通过率、重试次数和人工修正时间更适合你的交付。

## 先按交付风险分流

把每个项目先放进下面三条路线。它们是起点，不是"模型等级表"。若实际验收记录与预期不同，应按失败原因升档或降档。

| 先问什么 | 先选哪条路线 | 何时停止继续使用这条路线 |
| --- | --- | --- |
| 只要 1K 预览、方向稿、背景变体或实时交互候选吗？ | **Nano Banana 2 Lite**：gemini-3.1-flash-lite-image | 成品明确要 2K/4K，或 1K 已不能满足交付。 |
| 需要通用图像生成/编辑、更多尺寸选择、批量迭代或正式成品吗？ | **Nano Banana 2**：gemini-3.1-flash-image | 同一任务持续在文字、结构、参考一致性或人工返工上越过验收线。 |
| 这是高风险品牌资产、密集文字图、复杂 mockup 或需要更细控制的成品吗？ | **Nano Banana Pro**：gemini-3-pro-image | 若仍无法稳定满足 Logo、小字、精确色号、包装结构或合规文案，停止升档，转人工排版、校对或局部编辑。 |

第一步不是看名称里有没有 Pro，而是把交付尺寸、参考素材、图中文字、允许重试次数和最终审核责任写清。Lite 的官方文档明确限定 1K；当尺寸已经排除 Lite 时，继续比它的单价没有意义。Nano Banana 2 与 Pro 都可作为 2K/4K 候选，但是否升级应由实际失败成本决定。

## 三档的官方事实：模型 ID、尺寸和 API 价格

下表只整理 Google Gemini API 当前页面中的模型事实与标准图像示例价格，币种为美元。它不代表地区价格、消费级应用优惠、免费额度、供应商积分或套餐；这些入口必须在实际使用前另行核对。

| 路线 | 当前 API 模型 ID | 官方定位与尺寸边界 | 标准图像示例价格 |
| --- | --- | --- | --- |
| Nano Banana 2 Lite | gemini-3.1-flash-lite-image | 低延迟、高吞吐的图像生成与编辑；仅支持 1K，2K 和 4K 不支持。 | 1K 约 $0.0336。 |
| Nano Banana 2 | gemini-3.1-flash-image | 面向速度与高容量使用；提供 0.5K、1K、2K、4K 选项。 | 0.5K 约 $0.045、1K $0.067、2K $0.101、4K $0.151。 |
| Nano Banana Pro | gemini-3-pro-image | 面向专业图像编辑与生成，以及复杂图形设计、高保真产品 mockup 和需要准确文字的任务。 | 1K/2K 约 $0.134，4K 约 $0.24。 |

Google 的 [Nano Banana 2 Lite 模型页](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite-image) 还说明 SynthID 与 C2PA 水印始终开启；不要把 Lite 写成可用来绕过标记的低价替代品。Nano Banana 2 的 [模型页](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-image) 列出图像生成、Search grounding 与 Batch 支持；Pro 的 [模型页](https://ai.google.dev/gemini-api/docs/models/gemini-3-pro-image) 列出图像生成、Search grounding、Batch、Flex 和 Priority 选项。能力存在不等于你的地区、项目、平台或套餐必然可用。

价格也只回答一次生成的 API 账单，不回答最终交付成本。Google 的 [价格页](https://ai.google.dev/gemini-api/docs/pricing) 对这三条图像 API 路线标示 Free Tier 为不可用；应用端赠额、区域政策和第三方收费不能从这张表反推。GPT88 统一网关等接入方式的价格与配额以 gpt88.cc 控制台为准。

## 用同一输入做通过验收成本测试

不要拿 Lite 跑简单提示词、Pro 跑复杂提示词，再把两张结果当作比较。用一张固定测试卡，三条路线只改变模型 ID；尺寸不兼容的路线要标为"不适用"，而不是硬凑进同一轮。

| 测试卡字段 | 固定内容 | 要记录的结果 |
| --- | --- | --- |
| 输入 | 同一提示词、同一参考图、同一比例、同一输出尺寸和同一安全要求 | 输入是否完全一致；若 Lite 不支持目标尺寸，直接记为不适用。 |
| 验收 | 文字、主体结构、关键材质、参考一致性、尺寸、审核要求 | 每项通过/不通过，以及具体失败原因。 |
| 成本 | 每次生成费用、重试次数、人工修正分钟数、审核等待 | 不只记录最后保留的一张。 |
| 决策 | 通过验收成本 =（模型费用 + 人工修正成本）÷ 通过验收数量 | 只有 Pro 降低总成本或明显降低不可接受风险时才切换。 |

先准备你最常遇到的失败样本：带字海报、产品包装、参考图编辑、多区域信息图或最终 4K 主视觉。每类样本保持输入不变，记录三档各自的通过数与返工原因。这样得到的是自己的工作流证据，而不是把别人的单张样例当成普遍质量结论。

## 什么时候该升档，什么时候该停下

Lite 失败的原因若是尺寸边界，直接转 Nano Banana 2 或 Pro；若只是内部方向稿需要更多候选，继续留在 Lite 反而合理。Nano Banana 2 已覆盖通用的高效图像工作；不要仅因 Pro 的名称更高级就把全部流量切过去。

当同一输入下，Nano Banana 2 在文字准确性、复杂布局、关键参考一致性或高风险交付上反复失败，并且 Pro 能减少重试、人工修改或审核风险时，才有升级证据。反过来，若 Nano Banana 2 在允许的重试次数内稳定通过，就保留它。

Pro 也不是免检通行证。Logo、条码、小字、价格、日期、医疗/金融/法律等受监管文案、精确色号和产品结构，仍必须由负责的人或既定流程核验。若这些项目连续不稳定，继续换模型不能替代人工制作与合规审核。

## 常见误区

### 4K 就一定要用 Pro 吗？

不一定。Nano Banana 2 的官方资料也列出 4K 选项。4K 是候选条件之一；是否选 Pro，要看你的文字、结构、品牌约束和通过验收成本，而不是尺寸标签本身。

### Lite 是不是只适合低质量图片？

不是。Lite 的关键约束是 1K，而它的官方定位是低延迟、高吞吐图像生成与编辑。对草图、方向筛选和实时候选来说，1K 可能正好满足任务；对需要 2K/4K 的最终交付则不匹配。

### API 价格能代表我在任何入口的实际费用吗？

不能。官方 API、Gemini App、AI Studio、Vertex、企业项目和第三方包装层可能有不同的地区、额度、计费单位、失败扣费、数据条款和支持路径。先用本文选择模型路线，再对你计划使用的入口单独核实合同。若通过 GPT88 统一网关接入，价格与配额以 gpt88.cc 控制台为准。

### 一次生成谁更好看，能决定长期默认模型吗？

不能。一次样例无法证明普遍质量。至少比较一组与你的真实交付相近、输入保持一致的样本，并把重试、人工修正和审核责任计入通过验收成本。高风险资产在任何路线下都应保留停止条件和人工核验。

当你只需要比较官方 API 的三条图像路线时，先完成上面的测试卡；当问题是套餐、地区、额度或供应商收费时，应把它作为另一个待验证的问题，而不是把不相同的合同混进模型选择结论。
