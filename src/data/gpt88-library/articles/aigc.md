### 1. 使用边界

## 1. 使用边界

本指南适合面向 C 端用户、运营同学、内容创作者和测试同学快速编写多模态提示词。

**适用场景：**

| 类别 | 典型用途 | 重点说明 |
| --- | --- | --- |
| AI 绘图 | 海报、封面、商品主图、信息图、头像、品牌视觉 | 需要明确用途、主体、构图、风格、文字和比例 |
| 图像编辑 | 换背景、改颜色、多图合成、局部修改 | 必须拆开说明“保留什么”和“修改什么” |
| AI 视频 | 文生视频、图生视频、短视频素材 | 需要写清动作、镜头、时长、比例和连续性 |
| AI 漫剧 | 角色设定、分镜画面、剧情镜头 | 重点是角色一致性、镜头节奏和叙事重点 |
| 内容生产 | 小红书、视频号、公众号、电商、课程、PPT | 需要明确目标平台和发布裁切比例 |

**不适用场景：**

- 直接作为模型能力说明或计费说明。
- 直接承诺生成结果一定符合平台审核、广告法或品牌规范。
- 复制真实品牌、商标、人物肖像、受版权保护素材作为可商用模板。

### 2. 快速使用流程

## 2. 快速使用流程

1. **先选择任务类型：**绘图、修图、视频、漫剧、分镜或角色设定。
1. 替换模板中的方括号内容，例如 `[角色]`、`[场景]`、`[目标平台]`、`[时长]`。
1. 明确图片或视频的用途、比例、风格、主体和文字信息。
1. 如果是编辑任务，单独写出保留项和修改项。
1. 为每条提示词补充负面约束，避免水印、乱码、肢体错误、比例错误等问题。
1. 生成后按检查清单复核，必要时缩短文字、减少元素、强化主体或重新约束角色一致性。

### 3. 通用提示词结构

## 3. 通用提示词结构

> **建议**
> 推荐将提示词拆成稳定字段，而不是只写一段感觉描述。

~~~text
用途：[这张图或这段视频要用于什么]
主体：[人物、产品、场景或核心对象]
受众：[目标用户或观看人群]
平台：[小红书/视频号/公众号/电商/PPT/官网等]
比例：[1:1/3:4/4:5/9:16/16:9 等，按目标模型支持范围填写]
构图：[居中/三分法/左侧留白/顶部标题区/底部信息栏等]
风格：[写实/电影感/国风/动漫/科技/治愈/商业摄影等]
光影：[自然光/逆光/柔光/高反差/霓虹/清晨/夜景等]
文字：[只保留必要文案，说明位置和层级]
约束：[必须保留或必须避免的元素]
负面：[水印、乱码、Logo、畸形肢体、画面拥挤等]
~~~

### 4. AI 绘图与 Image 2

## 4. AI 绘图与 Image 2

### 4.1 基本定位

Image 2 更适合生成“有明确用途的图片”，例如封面、海报、商品图、信息图和视觉草图。提示词应围绕实际使用场景组织，而不是只追求“好看”。

**推荐把它当作：**

- **灵感生成器：**快速探索多个视觉方向。
- **视觉草图工具：**把想法变成可讨论的画面。
- **排版辅助工具：**先生成结构、构图和风格，再由人工精修。
- **商业内容助手：**服务短视频、公众号、小红书、电商、课程和 PPT 等内容生产。
### 4.2 图片生成模板

~~~text
请生成一张用于 [目标平台/业务场景] 的 [图片类型]。

主体是：[核心人物/产品/场景]。
画面用途：[传播、销售、说明、封面、展示等]。
构图：[画幅比例、主体位置、留白区域、标题区域]。
风格：[视觉风格、参考质感、色彩倾向]。
光影：[光线方向、氛围、景深、质感]。
文字：[主标题、副标题、小字说明，要求清晰可读]。
细节：[道具、环境、材质、装饰元素]。
限制：[不出现品牌名、Logo、二维码、水印、无关人物等]。
~~~

### 4.3 图像编辑模板

编辑图片时，重点是说明修改范围和保留范围。

~~~text
请基于参考图进行编辑。

必须保留：
- [主体身份/产品形状/五官/发型/服装/构图/颜色等]

需要修改：
- [背景/光线/颜色/文案/局部元素/画面比例等]

输出要求：
- 风格统一，边缘自然，主体不变形。
- 不新增无关文字、Logo、水印或多余人物。
- 如果包含文字，文字要少、清晰、可读。
~~~

### 4.4 常用图片场景

| 场景 | 提示词重点 |
| --- | --- |
| 个人头像 | 人物特征、表情、背景氛围、头像裁切 |
| 小红书封面 | 平台比例、标题层级、留白、主体吸引力 |
| 公众号/视频号封面 | 标题区、品牌色、清晰主视觉 |
| 电商产品主图 | 产品角度、材质、卖点、干净背景 |
| 产品爆炸图 | 零件层级、箭头说明、信息密度 |
| 城市或美食地图 | 地标、路线、插画风格、标注清晰度 |
| 教育信息图 | 流程、模块、图标、可读性 |
| 视频封面缩略图 | 强主体、强情绪、少文字、高对比 |
| 漫画故事板 | 镜头数量、角色动作、剧情顺序 |
| 品牌视觉板 | 色彩、字体、图形语言、应用物料 |
| UI/App 样机 | 设备框、界面结构、业务信息层级 |
| PPT 单页图 | 标题、模块、图表、留白 |
| 写实产品场景图 | 场景可信度、光影、产品不变形 |
| 节日营销海报 | 节日元素、活动信息、商业约束 |

### 4.5 图片负面约束

**可按任务补充以下约束：**

~~~text
避免低清晰度、画面模糊、文字乱码、水印、二维码、Logo、真实品牌名、无关人物、肢体变形、多手、多脸、主体跑偏、过度磨皮、塑料质感、画面脏乱、排版廉价、信息拥挤。
~~~

### 5. AI 视频与漫剧

## 5. AI 视频与漫剧

### 5.1 通用视频生成模板

~~~text
请生成一段用于 [目标平台] 的 AI 视频提示词。

主题：[视频主题]
人物：[身份、年龄、外貌、服装、情绪]
场景：[时间、地点、环境、氛围]
动作：[人物或主体正在做什么，动作节奏如何]
镜头：[景别、机位、运镜方式]
风格：[写实/电影感/动漫/国风/赛博朋克/治愈等]
光影：[自然光/逆光/霓虹/柔光/高反差等]
时长：[秒数]
比例：[16:9/9:16/1:1 等]
要求：主体清晰、动作连贯、前后帧一致、无多余文字、无水印、无畸形肢体。
~~~

### 5.2 图生视频模板

~~~text
请以参考图为基础生成视频。

保留参考图中的主体外观、服装、发型、颜色、场景和构图。
主体动作：[动作描述]
镜头运动：[轻微推进/缓慢环绕/横向跟拍/俯仰移动等]
背景变化：[环境变化]
整体氛围：[情绪氛围]
视频风格：[电影感/动漫/写实/梦幻等]
要求：运动自然、画面稳定、主体不变形、光影连续，不新增无关人物或文字。
~~~

### 5.3 AI 漫剧单镜头模板

~~~text
生成 AI 漫剧镜头画面。

角色：[角色名称和固定外貌]
服装：[固定服饰和标志物]
场景：[地点、时间、环境]
动作表情：[动作、情绪、眼神]
镜头：[景别、机位、运镜]
画面情绪：[紧张/治愈/悬疑/浪漫/反转等]
风格：[漫画/动画/电影感/国风/都市等]
光线色彩：[主色调、光源、氛围]
要求：角色形象一致，五官清晰，构图有叙事重点，不出现错字、水印、畸形手指或多余肢体。
~~~

### 5.4 分镜脚本模板

~~~text
请把以下剧情改写成 AI 视频分镜脚本。

剧情：[粘贴剧情]
目标平台：[抖音/快手/视频号/小红书等]
单集时长：[时长]
画幅比例：[比例]

请输出表格：
镜头编号、时长、画面内容、角色动作、对白/旁白、景别、机位、运镜、音效/音乐、AI 视频提示词。

要求：
- 每个镜头只表现一个清晰动作。
- 镜头之间有情绪递进。
- 开头有钩子，结尾保留悬念或行动引导。
~~~

### 6. 漫剧创作流程与角色一致性

## 6. 漫剧创作流程

**完整创作可以拆成六步：**

| 步骤 | 产物 | 检查重点 |
| --- | --- | --- |
| 1. 故事素材 | 故事梗概、冲突、人物关系 | 主角、目标、障碍和反转是否清楚 |
| 2. 角色设定 | 角色卡、服装、标志物 | 后续镜头能否稳定复用 |
| 3. 场景设定 | 场景库、时间、天气、道具 | 场景是否服务剧情 |
| 4. 分镜脚本 | 镜头表、对白、旁白 | 每个镜头是否只有一个重点动作 |
| 5. 画面提示词 | 绘图提示词、视频提示词、负面词 | 角色一致性、构图、光影和比例 |
| 6. 发布优化 | 标题、封面、配音、节奏 | 平台适配、裁切、可读性 |

## 7. 角色一致性

角色一致性应通过“角色卡 + 固定前缀 + 每轮重复约束”实现。

**角色卡字段建议：**

| 字段 | 示例说明 |
| --- | --- |
| 角色代号 | 用于后续提示词复用的唯一名字 |
| 身份关系 | 职业、关系、阵营、剧情功能 |
| 年龄气质 | 年龄段、性格、人物气质 |
| 脸型五官 | 脸型、眼睛、鼻子、嘴唇、明显特征 |
| 发型发色 | 长度、颜色、刘海、发饰 |
| 固定服装 | 主造型、备用造型、材质与颜色 |
| 标志物 | 饰品、道具、纹身、伤疤等 |
| 动作习惯 | 常见姿态、手势、表情 |
| 不可改变项 | 每轮生成都必须保留的特征 |
| 负面约束 | 不换脸、不换发色、不换服装、不丢失标志物 |

**固定前缀模板：**

~~~text
[同一角色：角色代号]，[年龄与身份]，[脸型与五官]，[发型发色]，[固定服装]，[标志物]，[气质关键词]，[不可改变项]，[本镜头动作和场景]
~~~

**注意事项：**

- 多轮修改时不要只写“和刚才一样”，应重复关键保留项。
- 如果使用参考图，仍然要用文字写清需要保留的特征。
- 角色、产品和场景的一致性要求应分别写，不要混在一句话里。
## 8. 镜头与运镜字段

| 字段 | 可选写法 |
| --- | --- |
| 景别 | 远景、全景、中景、近景、特写 |
| 机位 | 平视、低角度、俯拍、侧面、背面、主观视角 |
| 运镜 | 推进、拉远、环绕、横移、跟拍、摇镜、固定镜头 |
| 节奏 | 缓慢、稳定、紧张、快速、顿挫、逐步推进 |
| 光影 | 柔光、逆光、轮廓光、霓虹、高反差、自然光 |
| 情绪 | 治愈、紧张、压迫、浪漫、悬疑、热血、失落 |
| 连续性 | 服装不变、发型不变、道具不变、背景逻辑连续 |

### 8. 镜头与运镜字段；9. 常见问题与修正；生成检查

## 9. 常见问题与修正

| 问题 | 常见原因 | 修正方向 |
| --- | --- | --- |
| 文字乱码 | 文案太多、字号太小、层级太密 | 减少到 1-2 行，要求清晰可读，放大标题 |
| 画面太乱 | 元素过多，背景和主体争抢注意力 | 减少背景元素，增加留白，强化主体位置 |
| 人物不像原图 | 保留项写得不够明确 | 重复角色卡，写清五官、发型、服装和标志物 |
| 产品变形 | 修改范围覆盖到产品本体 | 明确只改背景、光线或文案，不改变产品形状 |
| 海报像模板 | 风格描述太泛 | 补充行业、平台、受众、色彩和版式要求 |
| 信息图拥挤 | 模块过多，文字没有层级 | 控制在 3-5 个模块，增加间距和标题层级 |
| 视频闪烁 | 动作、镜头和主体约束不足 | 减小动作幅度，固定主体特征和镜头节奏 |
| 角色变脸 | 多轮生成没有重复一致性约束 | 每条镜头提示词都带固定角色前缀 |

## 10. 生成前检查清单

- 是否说明图片或视频的用途。
- 是否说明目标平台和画幅比例。
- 是否说明主体是谁或是什么。
- 是否说明标题文字和文字位置。
- 是否说明视觉风格、色彩和光影。
- 是否说明不要出现什么。
- 如果是编辑图，是否说明必须保留什么。
- 如果是漫剧或视频，是否说明角色一致性和镜头连续性。
## 11. 生成后检查清单

- 文字是否清晰可读，是否有乱码。
- 人物是否变形，五官和手部是否正常。
- 产品是否保持原形，Logo 或包装是否被误改。
- 主体是否突出，画面是否拥挤。
- 是否出现多余水印、二维码、品牌名或无关人物。
- 视频是否有闪烁、跳切、主体漂移或服装变化。
- 是否符合目标平台的裁切比例。
- 是否需要人工二次排版或修图。
## 12. 文档维护约定

- 内容更新时，优先同步结构、方法和检查清单，不固化完整提示词库。
- 新增案例时使用自造示例，避免包含真实密钥、账号、版权素材、真实品牌或不可授权肖像。
- 涉及模型尺寸、透明背景、计费或接口能力时，以项目实际支持能力和官方文档为准。
- 若后续要把本指南展示到前端，需要按 `web/src/i18n/` 的现有国际化规则补齐翻译。
