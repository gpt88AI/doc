### Box CEO Aaron Levie

Aaron Levie 认为，agent swarm 会把 AI 的生产率提升再推高一个数量级：从聊天式的即时辅助，到能独立完成整项任务的 agent，再到围绕目标自行寻找路径的 agent 集群。凡是价值创造受限于研究、决策、数据处理或代码生成的数字化工作，都可能被这种模式重构；围绕 agent 的 harness、应用和基础设施也会形成新的 FDE 工作领域。

他还宣布 Box 与 Anthropic 合作，让 Claude 通过 MCP 对 Box 内容进行完整读写：agent 可以读取资料、创建或修改合同和演示文稿，并把更新写回 Box。企业文件会被 agent 处理得远多于今天，内容平台需要同时解决可用性与安全性。

### Vercel CEO Guillermo Rauch

Guillermo Rauch 分享 Vercel Security Review 上线不到一周的结果：发现 57,897 个漏洞，其中 6,029 个为 critical 或 high，已有 14,665 个由 agent 自动修复。这个数字说明，许多原本会被忽略的安全问题可以被持续扫描和修补，而且能力不依赖应用部署在哪里。

他还判断，agentic coding 会让 Rust 之外的专用语言、C 甚至 LLVM IR 和 assembly 重新获得空间。AI 让软件变得更流动，语言不必再承担“一套方案适合所有场景”的角色。

### Every CEO Dan Shipper

Dan Shipper 发布了对 Gemini 4 Carbon 的首日测试：在 Every 的 Senior Engineer benchmark 中得分 44%，高于 Argon 的 21%；它能长时间推进大型项目，也能生成浏览器 3D 模型、视频编辑器更新和音视频剪辑。但 Carbon 有明显边界：可能持续工作到该停却不停，生成巨大的单体文件，且写作表现与 Argon 接近、较高价格暂时不足以支持全面切换。

他的实际建议是给 Carbon 一个范围清楚、可验收的大任务，并认真 review 结果；在音频和视频场景可以把它当作第二意见。

### Latent Space：Designing for Agents — Zeno Rocha, Resend

**核心观点：** 面向 developers 的基础设施产品，不能只把 API 做出来，还要把 deliverability、滥用防护和 agent 时代的使用方式一起产品化。

Resend CEO Zeno Rocha 从前端和开源背景进入 email 基础设施，Resend 已服务 430 万用户和超过 12 万付费客户。他解释了高并发邮件为什么不能简单地把任务丢进队列：Gmail、Outlook 和 Yahoo 的规则不同，发送速度、IP 池、域名声誉、退信和投诉率都必须持续观测。产品因此需要把 link checker、spell checker、HTML 到 plain text 的自动转换等最佳实践内置进去，降低开发者学习一套复杂行业规则的成本。

更具启发性的判断是“默认信任，快速纠偏”：平台不应先把所有新用户关进人工审核流程，而应在发现异常时迅速限制并区分误用与滥用。Rocha 也谈到 AI-native 公司的组织方式：agent 可以参与 marketing research、SEO 实验和内容运营，但关键实验仍需要人签字，企业产品也不能只是在个人版上加 SSO 和 audit logs，而要重新设计 enterprise 工作流。
