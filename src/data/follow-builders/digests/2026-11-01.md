### No Priors：Taking on ServiceNow: Coding Agents the Rest of Us with Serval Co-Founder and CEO Jake Stauch

**核心观点：** Jake Stauch 认为，企业要让 coding agents 真正进入日常工作，关键不是给每个人一个权限过大的个人 agent，而是把代码生成能力放进 IT 能治理、审批和审计的工作流。

Stauch 是 Serval 联合创始人兼 CEO。Serval 面向企业服务管理与自动化，希望让 IT 团队用 coding agents 构建密码重置等确定性流程，再把能力扩展到 HR、财务、法务等部门。他的判断是，企业员工的个人权限通常不足以让通用 agent 跨系统办事；要使用更高权限，就必须配套明确的审批、暂存、审计记录和一次性访问流程。

这也解释了 Serval 为什么把 IT 团队作为入口：多数公司有 IT 部门，却没有能为每个内部需求开发软件的工程团队。Stauch 认为，代码比拖拽式流程编辑器更适合表达复杂自动化，而 coding agents 让更多人能编写这类代码。他把核心洞察概括为：“IT actually wants to build stuff.” 对企业产品而言，自动化能力与权限治理需要一起设计，不能只追求 agent 的自主程度。
