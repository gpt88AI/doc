## 一句话结论

今天的核心信号是：agent 的 eval 应该直接成为产品规格，企业需要在真实工作环境中持续测试 agent；与此同时，类型系统和本地文件访问等边界正在变成 agent 工作流的基础设施，产品构建也越来越强调从具体需求出发快速验证。

### AI 教程作者 Peter Yang

Peter Yang 分享了一个可复用的 AI app 构建路径：用自己的 spec skill 先明确关键设计，再接入 Gemini Live API 做实时语音，最后用 Nano Banana 生成 diorama 风格的视觉素材。他把这个过程做成了语言学习 app 教程，目标是让用户在旅行前用 live voice calls 学会任意语言的 100 个短语。

来源：https://x.com/petergyang/status/2107108755699900459

### Madhu Guru（Meta AI 高级总监）

Madhu Guru 认为，团队最常见的错误是把 eval 当成 agent 完成后的额外 QA 步骤。AI 产品与传统软件不同，eval 不只是验收工具，而应该直接定义产品要达到的行为和质量标准。

来源：https://x.com/realmadhuguru/status/2107292113214091355

### Thariq（Claude Code，Anthropic）

Thariq 观察到，先把规划表达成可复用的组件、状态机、图表和代码片段，能比直接生成原始 HTML 更节省 token，因为模型不必反复重建相同的组件和逻辑。他还把“local hands”称为一种新的工作模式：Claude 在云端运行，却能访问本地文件，这一模式也将进入 Cowork。

来源：https://x.com/trq212/status/2107294499282293017

来源：https://x.com/trq212/status/2107229483015258493

### Replit CEO Amjad Masad

Amjad Masad 指出，美国正在追赶 open-weights 模型。这条判断把竞争焦点放在开放权重模型的供给和生态追赶上，而不只是单个产品的发布节奏。

来源：https://x.com/amasad/status/2107222388429766970

### Vercel CEO Guillermo Rauch

Guillermo Rauch 发布了 gdp-ts：一个面向 TypeScript 的库、linter 和 AI skill，用“proof”要求调用者先完成授权检查，再允许调用敏感函数，类型检查器会在编译期验证这些 proof。这个设计把过去在 Haskell 等生态中较小众的安全模式，转化成更适合 agent 高频写代码场景的硬约束。

来源：https://x.com/rauchg/status/2107119811444748555

### Box CEO Aaron Levie

Aaron Levie 认为，很多 agent 的采用和部署都卡在真实工作环境中的测试、调优与优化：agent 要访问企业文件、CRM 和邮件，团队还要判断模型或工作流升级后表现是否会变化。企业最终会需要专门负责 eval 的人员、基础设施和模拟环境，但现在仍往往只能逐个企业手工完成。

来源：https://x.com/levie/status/2107283615247999257

### 前 Cursor、Notion 与 Stripe 设计师 Ryo Lu

Ryo Lu 分享了一个面向语言学习者的浏览器工具：在 Netflix 中同时显示两种语言的字幕，并为日语、中文和韩语提供发音指南，样式也可以自定义。这是一个从具体学习场景出发，把多语言内容和辅助信息组合到观看流程中的小型产品实验。

来源：https://x.com/ryolu_/status/2107146629338042853

### YC 总裁兼 CEO Garry Tan

Garry Tan 认为，实验室提供的 harness 有消耗 token 的激励，因此创业公司的 harness 可以通过把 token 消耗转换为确定性、可测试、可重复的代码来提供实际效用。他还提到，AGI science loops 会出现新的 Muse/Instinct 类工具，Halmos 正在构建这类系统。

### SPC 合伙人 Aditya Agarwal

Aditya Agarwal 提出，若能在本地运行 Muse/Dot 这类“computer”，它可能比越来越受限的 macOS 更适合作为 agent 环境。这个设想把 agent 的可操作范围、运行位置和操作系统控制权放在了一起讨论。
