## 一句话结论

今天的主线是：个人 agent 正从单人对话工具走向可迁移、可协作、可执行的工作系统，软件 agent 也开始把测试、部署和验证串成完整闭环。Brian Armstrong 则把另一条重要趋势讲得很具体：如果 agent 要独立完成支付、购买服务和调用专用工具，就需要自己的账户、支付协议与可编程金融基础设施。

### Guillermo Rauch · Vercel CEO

Guillermo Rauch 分享了一次 agent 做软件 QA 的经历：他指出移动端应用内浏览器的渲染问题后，agent 自己复现问题、模拟环境、修复代码、部署临时 Vercel 环境，再交给 iPhone simulator 验证。他强调，这种从发现问题到部署后验证的完整链路，展示了 agent 在高强度、重复性软件质量工作上的优势。

### No Priors · Coinbase’s Everything Exchange: Agentic Finance, Stablecoins, and Tokenization with CEO Brian Armstrong

**一句话结论：**Brian Armstrong 的核心判断是，agentic economy 要真正运转，agent 不仅要能调用工具，还要拥有自己的账户、支付能力和可组合的金融基础设施。

Brian Armstrong 是 Coinbase 联合创始人兼 CEO，也是长寿生物科技公司 New Limit 的联合创始人之一。他把 Coinbase 的方向概括为 Everything Exchange、stablecoin payments 和 Agentic Finance：未来的 agent 可能需要使用独立的 spend account 来购买服务、启动云资源或向其他专业 agent 付费，而传统银行卡对几美分级交易并不经济。对这类小额、机器之间的支付，stablecoin 和 X402 这样的协议更适合成为基础设施。

他还描述了 Coinbase 内部的软件开发方式：每个团队或代码仓库都维护一份“brain”，记录事故、财务控制、实验结果和历史 PR。agent 修改服务时读取这份上下文；人类审查发现遗漏后，修正内容也要回写到 brain，让后续任务持续变好。这把一次性的代码生成变成了带反馈的 recursive self-improvement 系统。与此同时，他认为 AI 提升的首先是任务完成速度和现有团队的产出，不必简单等同于所有公司都会缩减到极小规模。

他对 agentic economy 的概括是：“There'll be more agents than humans in the not too distant future.” 这不是单纯的数量预测，而是对基础设施方向的判断：当 agent 成为服务的购买者、调用者和协作者，账户、支付、专业化 agent 市场以及面向 agent 的产品设计都会成为新的产品边界。
