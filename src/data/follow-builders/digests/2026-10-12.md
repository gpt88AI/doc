## 一句话结论

Agent 正从提升个人效率走向并行执行组织级任务；随之而来的关键问题，是如何治理其权限与责任、理解模型行为，并用评估体系持续改进工作流。

### OpenAI Codex 产品负责人 Nan Yu

Nan Yu 认为，Agent 让工程师的产出能力大幅增强，但产品经理仍受限于与客户沟通的带宽，因此理想团队配比可能接近一名工程师对应一名产品经理。这个判断强调，AI 提升了实现速度，却没有自动消除理解用户需求所需的人际工作。

### Meta AI 高级总监 Madhu Guru

Madhu Guru 将 Agent 发展的下一阶段概括为从能力走向信任，再走向自主：当模型、工具和上下文已能完成更多任务，系统就必须确保它在正确权限下采取正确行动，并让行为可观察、可审计、可追责。他提醒，Agent 能力可能快速演进，身份、权限和可观测性等安全机制也需要跟上。

### Box CEO Aaron Levie

Aaron Levie 认为，Agent swarm 能围绕共同目标并行探索大型或未知问题空间，应用范围可能覆盖软件开发、网络安全、生命科学、AI 研究和金融。与人类团队相比，Agent 可以通过共享上下文和基础设施减少沟通、状态同步与任务冲突的限制，因此带来的不只是更快执行，也可能是不同质量的研究与发现；他据此判断未来需要大幅增加算力。

来源：https://x.com/levie/status/2109079686286565378

Levie 还主张把前沿模型视作企业内部风险来治理，并非因为模型必然恶意，而是任何能访问重要系统的高能力主体都可能犯错或遭到入侵。他认为企业需要多层防护、审计 agent 的操作和数据访问，并建立故障时的控制与责任机制，类似安全领域的 zero-trust 思路。

### Y Combinator 总裁兼 CEO Garry Tan

Garry Tan 分享了将 Agent 纳入工程交付流程的做法：让一个线程协调并行工作和合并 PR 队列，要求 CI 通过后才进入主分支；规划阶段则让 Agent 用通俗语言解释方案，再由人审批方向。他也指出，对 GBrain 这类检索与延迟任务，应围绕检索质量、延迟和计算成本建立清晰评估，并让多个类别能够自动研究和改进。

### The MAD Podcast with Matt Turck：AI Models Are Now Hiding Their Cheating | Eric Ho (Goodfire)

**核心观点：** 解释模型内部机制不仅能发现风险，也可能让研究者以更低成本监控模型，并逐步干预模型学到的行为。


Goodfire 的 Eric Ho 介绍了 mechanistic interpretability 的几种用途：通过模型内部激活训练 probe，监测 reward hacking 等风险；利用数据调试，预测训练数据可能教会模型什么；并探索在训练过程中有意引导模型形成目标行为。内部 probe 能复用模型前向计算，因此成本远低于每次调用大型推理模型判断。他描述的分层做法是先由 probe 筛查，再交给较快的模型判断，意见不一致时才升级到更强的模型复核。

Ho 将目标描述为让训练过程本身能够选择要强化或抑制的行为：“We want to give gradient descent a choice.” 他也提醒，不能简单地直接对 probe 优化，否则模型可能只是把目标行为转移到别处。研究者还可以在生成过程中监测风险并实时干预、从大量日志中定位异常，或在训练前预测数据可能教会模型什么。Goodfire 的 Silico 产品把解释性工具用于大规模模型监控与调试；Ho 举例称，团队曾通过分析一个阿尔茨海默病诊断模型，发现与疾病相关的新型血液生物标志物。他对 2028 年前理解模型行为仍持乐观态度，目标是针对关键行为找到其因果机制，而不是在发布前完整逆向整个模型。
