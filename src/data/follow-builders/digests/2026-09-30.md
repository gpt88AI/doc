## 一句话结论

今天的有效信号集中在模型效率如何转化为实际工作：多位 Anthropic 工程师称 Sonnet 5.5 能以更少 token 完成更多任务，Box 的早期企业评测也报告了速度与任务表现提升；与此同时，OpenAI 将调整 Pro $200 订阅的用量计算方式。产品团队给出的数字仍是各自的测试与体验，应结合具体任务自行验证。

### OpenAI Codex 与 ChatGPT 团队成员 Thibault Sottiaux

Thibault Sottiaux 表示，Pro $200 订阅将于 9 月 30 日重新向新用户开放，同时调整用量计算；按他的换算，新方案对应的 API spend 约为旧方案的一半。他还表示不会恢复 5 小时使用上限，并称模型效率带来的 API 降价会逐步传递给用户；额外增加的订阅权益尚未公布。

来源：https://x.com/thsottiaux/status/2104823812042940713

### Claude Code 工程师 Boris Cherny

Boris Cherny 称，Sonnet 5.5 修复 Claude Code 中一个 bug 时，速度提高约 30%，用量减少约 30%。这是一项来自团队成员的产品体验报告，帖子没有给出独立评测方法。

来源：https://x.com/bcherny/status/2104638725317923228

### AI 教程与访谈创作者 Peter Yang

Peter Yang 用 Sonnet 5.5 做了一个可玩的 StarCraft 关卡：玩家操纵 Terran 防守 Zerg，可建造 Marines、Siege Tanks 和 Battlecruisers。素材使用了 StarCraft II 模型与 Suno 生成的音乐，模型也制作了展示视频，呈现了从玩法到视听素材的多步创作流程。

来源：https://x.com/petergyang/status/2104736498151256303

### Claude Code 与 Cowork 工程师 Cat Wu

Cat Wu 称，Claude Code 用户使用 Sonnet 5.5 时，相比 Sonnet 5 平均能多完成约 30% 的任务，因为模型更聪明、同样工作所需 token 更少。她举例说，在一次调用工具清理院子的演示中，Sonnet 5.5 快了 24 秒并少用了约 6,000 个 token。

来源：https://x.com/_catwu/status/2104639552170377399

### Claude Code 工程师 Thariq

Thariq 认为，agent 工作已经不只是展示一段 prompt：他会让 agent 先参考自己做过的多个代码仓库、搜索资料，并结合其他 API、skills 和 examples。针对 projects、Claude 标签和动态 workflows 的 token 成本顾虑，他建议试试 Sonnet 与 Opus 5.5，称这类能力现在更容易负担。

### Vercel CEO Guillermo Rauch

Guillermo Rauch 表示，现在可以无需认证地搜索 Vercel 域名，并特别指出这对 agent 很有用。这项变化把域名搜索从需要登录的操作变成 agent 可直接使用的能力。

来源：https://x.com/rauchg/status/2104764419305796094

### Box CEO Aaron Levie

Aaron Levie 分享了 Box 对 Sonnet 5.5 的早期企业任务评测：在 Box Agent 的复杂知识工作测试中，整体分数提高 4 个点，完成交付物约快 2.4 倍且少用 12% token。Box 还报告了金融服务、法律、生命科学和公共部门测试的提升；这些数字来自 Box 自己的评测，Levie 称 Sonnet 5.5 将很快加入 Box AI Studio。
