## 一句话结论

随着模型能执行更长任务并使用更多工具，AI 产品的竞争力可能更多来自对行业流程、企业数据和组织协作的深度适配；个人 agent 与公司 agent 也可能走向不同形态。

### 投资人 Nikunj Kothari

Nikunj Kothari 分享了对 Wabi 2.0 的使用体验：由一个主 agent 统筹、按具体主题生成可分享且会归档的短期对话，让旅行或报税等任务各自拥有清晰上下文。他认为这种设计比长期堆积多个 agent 对话更容易管理，但产品仍需调低过度主动的程度并改善应用体验。

### AI & I by Every：Why Every Traded Personal Agents for One Company Agent

**核心观点：** 个人 agent 适合个性化生活场景，公司 agent 则能把维护成本和工作上下文集中起来；组织需要根据使用目标选择，而不是让每个人各自维护一套系统。

Every 的主持人与平台负责人 Willie Williams 回顾了团队从个人 agent 转向公司级 agent 的过程。个人 agent 能让员工互相看到新的 AI 用法，但部署、安全和持续维护很快变成负担；团队发现，与其让每个人反复修补自己的 agent，不如把精力投入一个共享的公司 agent，让共同积累的工作流和上下文持续发挥作用。

两人认为，工作场景更需要稳定、共享、理解组织流程的 agent，个人场景则仍有强烈的定制需求。Willie 还提到，AI 让管理者更容易汇总 Slack、邮件、客户反馈和项目指标，识别异常并路由提醒；但管理工作的核心仍是判断瓶颈、帮助团队和进行沟通，更多 token 并不能替代这些工作。
