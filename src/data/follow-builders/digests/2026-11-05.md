### Box CEO Aaron Levie

Aaron Levie 认为，AI 带来的生产力差距正在快速拉大：两年前，即使在编程等高度匹配的领域，优秀使用者的提升大约只有 30% 到 50%；现在，长时间任务、agent harness、更好的训练数据和多 agent 协作，让部分领域的上限可能达到 5 到 10 倍。结果是，是否处在 AI 使用前沿，正在从渐进式优势变成数量级差异。

### Unsupervised Learning：Ep 96: Nebius CTO on Racing the Hyperscalers Before AWS Wakes Up

**核心观点：** AI cloud 的竞争壁垒不只是 GPU 数量，而是能否把硬件、虚拟化、存储、网络和软件平台整合成可规模化的云产品。

Nebius CTO Neela 认为，公司把自己定位为 AI cloud，而不是笼统的“neo cloud”，目标是服务那些需要大规模训练和推理、但又无法完全依赖 AWS、Google Cloud 或 Azure 的客户。Nebius 的软件优先路线来自一个现实判断：同一平台既要支撑数万 GPU 的集群，也要让单 GPU 用户能以自助方式使用。

新一代 NVIDIA 芯片从原型、样片到量产会不断变化，云厂商必须同步修改虚拟化、存储、网络和隔离机制，有时还要把新问题反馈给 NVIDIA 并共同修复。随着训练规模扩大，存储吞吐和延迟也成为核心约束，单一共享卷达到数百 GB/s 已经是客户预期。她还强调，独立 AI cloud 的机会在于服务中型客户，而不是只做内部算力池。
