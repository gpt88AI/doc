人像提示词别靠玄学：用参考图、视线和姿态写出可控画面

AI 图像2026-10-2412 মিনিট পড়ুনAI绘画人像生成提示词参考图图像工作流

本文根据 Alex · Selin 的原始 X 长文整理。原帖发布于 2026 年 10 月 22 日，主题是用简单、准确的提示词生成有情绪的人像。下面保留原帖的方法论并重新组织为练习流程；示例中的具体画面和提示词属于作者的示范，不代表任何模型的固定能力或保证结果。

先记住一个公式

人物的情绪感，不是靠堆一串形容词，而是由四组信息共同决定：

情绪 = 表情 + 视线 + 动作姿态 + 环境氛围
  • 表情描述嘴角、眉眼和面部的松紧程度。
  • 视线说明人物在看镜头、看某个物体，还是看向画外。
  • 动作姿态说明身体朝向、手放在哪里，以及身体由什么支撑。
  • 环境氛围用光线、天气、空间和可见物件强化情绪。

这四组信息可以分别修改。一次只改变其中一组，才容易判断是哪句话让画面变好了或变坏了。

第一步：先准备一张正面参考图

参考图的任务是固定“这个人是谁”，而不是一次性提供所有姿势。优先选择头摆正、双眼连线基本水平、下巴自然、视线看向镜头的近距离照片。表情尽量放松，不要让夸张的笑容、歪头或遮挡成为身份特征。

如果现有参考图的角度不理想，可以先做一次参考图修正。原帖给出的写法可以概括为：保留脸型、五官、发型和肤色，把头部摆正，拍到头顶至锁骨，使用浅灰背景和均匀柔光。重点是“保留身份信息、只修正姿态和光线”，不要趁机换脸或加入新的风格。

上传这张正面特写后，后续提示词只需要写“脸型五官按正面参考图”，再补充服装、表情、视线和动作。这样比每次重新描述一遍五官更稳定，也更容易排查问题。

第二步：把动作写成可检查的结构

人物动作不要只写“自然地坐着”或“优雅地喝咖啡”。可以按照下面的顺序写：

身体朝向 + 主动作 + 支撑点 + 视线

例如，“坐在窗边，浅浅微笑，看向白瓷杯；前臂放在桌上，一手握杯把，一手扶住杯身”。这句话同时交代了空间关系、表情、视线、手部动作和支撑点。模型更容易理解，生成结果也更容易检查。

手部尤其需要支撑点。写清楚“肘部落在桌面”“前臂放在桌上”“肩膀放松”，比只写“手部自然”更有用。手指沿着杯把或杯身弯曲，也比“优雅的手势”更具体。

第三步：先把人物写清楚，再补环境

一条适合练习的提示词可以分成两步。

先确定人物

先上传正面参考图，只写身份、服装、表情、视线和动作。例如：

脸型五官按正面参考图。成年女性穿燕麦色针织开衫，坐在窗边，浅浅微笑，看向白瓷杯；前臂放在桌上，一手握杯把，一手扶杯身，肩膀放松。拍到腰部，双手和支撑肘入画，写实皮肤，16:9。

这一步先确认脸、身体关系和手部是否成立。不要在人物还不稳定时加入复杂的天气、背景故事或大量装饰。

再补可见环境

人物稳定后，再编辑上一张图，只改变环境信息。例如把光线改成雨后清晨的暖窗光，让玻璃出现雨珠，室内深处稍暗，同时明确保留脸、表情、视线、头部角度、双手和杯子的位置。

这种“保留已正确部分、只改一个变量”的方式，比从头生成一张完全不同的图片更容易得到连续结果。

第四步：少用同义词，避免指令互相打架

提示词越长不一定越准确。下面三类冲突很常见：

  • “柔和、温柔、温暖、亲切的微笑”重复表达同一件事，留下“柔和微笑”即可。
  • “面无表情”和“大笑”要求同一张脸呈现两个状态，应当二选一。
  • “托腮”和“双手捧杯”会争用同一双手，必须先决定哪个动作是主动作。

把每一轮修改限制在一个问题上：想换情绪时改表情或视线，想修僵硬时先改最紧绷的部位。其余已经正确的内容保留不动，并在对比时检查头部角度、笑意、杯子和双手是否仍然稳定。

用四种情绪练习同一套结构

同一张正面参考图可以练习不同情绪。每个例子只换关键变量，其他结构保持一致。

清冷：雨后街巷

组合可以是“不带笑 + 平静直视 + 肩背靠墙 + 松松交叠双臂”。环境使用蓝灰街巷、湿地和远处的暖灯，让冷暖对比承担一部分情绪表达。提示词中要写清双臂交叠的位置较低、手指放松，以及肩背确实由墙支撑。

俏皮：傍晚唱片店

组合可以是“坏笑 + 侧目一瞥 + 站立 + 头微歪”。头部只小幅偏斜，眼睛看向画面一侧，嘴角一侧轻扬。这样“俏皮”来自可见的动作关系，而不是单独添加一个抽象形容词。

沉思：暮色书桌

组合可以是“若有所思 + 看向窗外 + 坐着 + 托腮”。写明托腮的手与脸有接触、肘部落在桌面，另一只前臂自然放下，再用暮色窗光和一本合上的书补足情境。

释然：雨后海边

组合可以是“平和 + 轻闭双眼 + 自然站立 + 肩臂放松”。双臂松垂、肘部微弯、手指放松，配合远海薄雾、小浪和被微风带起的发梢与裙摆，让“放松”有具体的视觉线索。

一张可复用的提示词模板

可以把提示词拆成下面六段，按需要删减：

脸型五官按正面参考图。
人物身份与服装：年龄段、服装、发型和必要配饰。
表情与视线：嘴角、眉眼状态、看向哪里。
身体与手部：身体朝向、主动作、支撑点、手指状态。
环境与光线：地点、天气、光线方向、可见物件。
镜头与画幅：景别、需要完整入画的部位、比例。

先用模板得到一张可检查的基础图，再按顺序改表情、视线、姿态或环境。每次修改都记录“改了什么、保留了什么、结果哪里变了”，你会很快建立属于自己的词汇表。

让画面讲故事，而不是堆装饰

好的提示词不需要把所有细节都写满。让一个物件、一个视线方向和一个身体支撑关系承担叙事即可：白瓷杯说明人物正在做什么，雨珠和暖窗光说明此刻的天气与温度，合上的书暗示人物暂时停下了阅读。

当画面出现问题时，先问它属于哪一类：身份不稳定、情绪不明确、动作不成立，还是环境抢走了主体。找到类别后，只改对应的一句话。把提示词当成可迭代的画面说明书，远比寻找所谓“万能咒语”更可靠。

发布前的检查清单

  1. 参考图是否正面、无遮挡、表情放松？
  2. 是否明确写了人物看向哪里？
  3. 每只手是否只有一个清楚的任务，并有支撑点？
  4. 表情、视线、姿态之间是否互相冲突？
  5. 本轮是否只改变了一个主要变量？
  6. 画幅、景别和需要完整入画的部位是否写清楚？
  7. 生成结果中的脸、手、杯子或其他关键物件是否值得人工复核？
