AI 提示词汇总

面向图片、视频和 AI 漫剧场景，提供可复用的提示词结构、模板与质量检查方法。

适用范围：涉及账户、Key、模型、计费或接口的内容，请以 GPT88 当前控制台和对应 API 文档为准。

AI 提示词整理指南

  • **整理日期：**2026-07-23
  • **范围：**AI 绘图、Image 2、AI 视频、AI 漫剧、分镜脚本、角色一致性与常用检查清单

适用范围 本文整理可复用的方法、模板和检查口径；具体模型、参数和素材以 GPT88 当前文档为准。

1. 使用边界

1. 使用边界

本指南适合面向 C 端用户、运营同学、内容创作者和测试同学快速编写多模态提示词。

适用场景：

类别典型用途重点说明
AI 绘图海报、封面、商品主图、信息图、头像、品牌视觉需要明确用途、主体、构图、风格、文字和比例
图像编辑换背景、改颜色、多图合成、局部修改必须拆开说明“保留什么”和“修改什么”
AI 视频文生视频、图生视频、短视频素材需要写清动作、镜头、时长、比例和连续性
AI 漫剧角色设定、分镜画面、剧情镜头重点是角色一致性、镜头节奏和叙事重点
内容生产小红书、视频号、公众号、电商、课程、PPT需要明确目标平台和发布裁切比例

不适用场景：

  • 直接作为模型能力说明或计费说明。
  • 直接承诺生成结果一定符合平台审核、广告法或品牌规范。
  • 复制真实品牌、商标、人物肖像、受版权保护素材作为可商用模板。

2. 快速使用流程

2. 快速使用流程

  1. **先选择任务类型：**绘图、修图、视频、漫剧、分镜或角色设定。
  2. 替换模板中的方括号内容，例如 [角色]、[场景]、[目标平台]、[时长]。
  3. 明确图片或视频的用途、比例、风格、主体和文字信息。
  4. 如果是编辑任务，单独写出保留项和修改项。
  5. 为每条提示词补充负面约束，避免水印、乱码、肢体错误、比例错误等问题。
  6. 生成后按检查清单复核，必要时缩短文字、减少元素、强化主体或重新约束角色一致性。

3. 通用提示词结构

3. 通用提示词结构

建议 推荐将提示词拆成稳定字段，而不是只写一段感觉描述。

用途：[这张图或这段视频要用于什么]
主体：[人物、产品、场景或核心对象]
受众：[目标用户或观看人群]
平台：[小红书/视频号/公众号/电商/PPT/官网等]
比例：[1:1/3:4/4:5/9:16/16:9 等，按目标模型支持范围填写]
构图：[居中/三分法/左侧留白/顶部标题区/底部信息栏等]
风格：[写实/电影感/国风/动漫/科技/治愈/商业摄影等]
光影：[自然光/逆光/柔光/高反差/霓虹/清晨/夜景等]
文字：[只保留必要文案，说明位置和层级]
约束：[必须保留或必须避免的元素]
负面：[水印、乱码、Logo、畸形肢体、画面拥挤等]

4. AI 绘图与 Image 2

4. AI 绘图与 Image 2

4.1 基本定位

Image 2 更适合生成“有明确用途的图片”，例如封面、海报、商品图、信息图和视觉草图。提示词应围绕实际使用场景组织，而不是只追求“好看”。

推荐把它当作：

  • **灵感生成器：**快速探索多个视觉方向。
  • **视觉草图工具：**把想法变成可讨论的画面。
  • **排版辅助工具：**先生成结构、构图和风格，再由人工精修。
  • **商业内容助手：**服务短视频、公众号、小红书、电商、课程和 PPT 等内容生产。

6. 漫剧创作流程与角色一致性

6. 漫剧创作流程

完整创作可以拆成六步：

步骤产物检查重点
1. 故事素材故事梗概、冲突、人物关系主角、目标、障碍和反转是否清楚
2. 角色设定角色卡、服装、标志物后续镜头能否稳定复用
3. 场景设定场景库、时间、天气、道具场景是否服务剧情
4. 分镜脚本镜头表、对白、旁白每个镜头是否只有一个重点动作
5. 画面提示词绘图提示词、视频提示词、负面词角色一致性、构图、光影和比例
6. 发布优化标题、封面、配音、节奏平台适配、裁切、可读性

7. 角色一致性

角色一致性应通过“角色卡 + 固定前缀 + 每轮重复约束”实现。

角色卡字段建议：

字段示例说明
角色代号用于后续提示词复用的唯一名字
身份关系职业、关系、阵营、剧情功能
年龄气质年龄段、性格、人物气质
脸型五官脸型、眼睛、鼻子、嘴唇、明显特征
发型发色长度、颜色、刘海、发饰
固定服装主造型、备用造型、材质与颜色
标志物饰品、道具、纹身、伤疤等
动作习惯常见姿态、手势、表情
不可改变项每轮生成都必须保留的特征
负面约束不换脸、不换发色、不换服装、不丢失标志物

固定前缀模板：

[同一角色：角色代号]，[年龄与身份]，[脸型与五官]，[发型发色]，[固定服装]，[标志物]，[气质关键词]，[不可改变项]，[本镜头动作和场景]

注意事项：

  • 多轮修改时不要只写“和刚才一样”，应重复关键保留项。
  • 如果使用参考图，仍然要用文字写清需要保留的特征。
  • 角色、产品和场景的一致性要求应分别写，不要混在一句话里。

8. 镜头与运镜字段

字段可选写法
景别远景、全景、中景、近景、特写
机位平视、低角度、俯拍、侧面、背面、主观视角
运镜推进、拉远、环绕、横移、跟拍、摇镜、固定镜头
节奏缓慢、稳定、紧张、快速、顿挫、逐步推进
光影柔光、逆光、轮廓光、霓虹、高反差、自然光
情绪治愈、紧张、压迫、浪漫、悬疑、热血、失落
连续性服装不变、发型不变、道具不变、背景逻辑连续

8. 镜头与运镜字段；9. 常见问题与修正；生成检查

9. 常见问题与修正

问题常见原因修正方向
文字乱码文案太多、字号太小、层级太密减少到 1-2 行，要求清晰可读，放大标题
画面太乱元素过多，背景和主体争抢注意力减少背景元素，增加留白，强化主体位置
人物不像原图保留项写得不够明确重复角色卡，写清五官、发型、服装和标志物
产品变形修改范围覆盖到产品本体明确只改背景、光线或文案，不改变产品形状
海报像模板风格描述太泛补充行业、平台、受众、色彩和版式要求
信息图拥挤模块过多，文字没有层级控制在 3-5 个模块，增加间距和标题层级
视频闪烁动作、镜头和主体约束不足减小动作幅度，固定主体特征和镜头节奏
角色变脸多轮生成没有重复一致性约束每条镜头提示词都带固定角色前缀

10. 生成前检查清单

  • 是否说明图片或视频的用途。
  • 是否说明目标平台和画幅比例。
  • 是否说明主体是谁或是什么。
  • 是否说明标题文字和文字位置。
  • 是否说明视觉风格、色彩和光影。
  • 是否说明不要出现什么。
  • 如果是编辑图，是否说明必须保留什么。
  • 如果是漫剧或视频，是否说明角色一致性和镜头连续性。

11. 生成后检查清单

  • 文字是否清晰可读，是否有乱码。
  • 人物是否变形，五官和手部是否正常。
  • 产品是否保持原形，Logo 或包装是否被误改。
  • 主体是否突出，画面是否拥挤。
  • 是否出现多余水印、二维码、品牌名或无关人物。
  • 视频是否有闪烁、跳切、主体漂移或服装变化。
  • 是否符合目标平台的裁切比例。
  • 是否需要人工二次排版或修图。

12. 文档维护约定

  • 内容更新时，优先同步结构、方法和检查清单，不固化完整提示词库。
  • 新增案例时使用自造示例，避免包含真实密钥、账号、版权素材、真实品牌或不可授权肖像。
  • 涉及模型尺寸、透明背景、计费或接口能力时，以项目实际支持能力和官方文档为准。
  • 若后续要把本指南展示到前端，需要按 web/src/i18n/ 的现有国际化规则补齐翻译。
