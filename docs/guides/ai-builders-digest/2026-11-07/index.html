Unsupervised Learning：Ep 97: Jev Creator on Decision Models, Benchmark Fatigue & Why the Labs Missed It

核心观点： AI 产品的长期价值取决于能否把模型放进可靠、可逆、能控制副作用的软件系统，而不是单纯追逐 benchmark 分数。

Jev Creator 认为，LLM 的下一步不应只是向人输出更漂亮的字符串，而应成为由软件调用的 machine-native cognitive core。开发者比模型提供方更清楚下游需要什么样的 reliability profile，因此模型应该暴露更多可调参数，让使用场景与模型能力共同演化。他反对把不同模型固定成一组僵化的“适用场景”，更希望 AI 像 SQL 一样可靠、可替换、provider agnostic。

他对 coding agent 的判断也很克制：平均生产力提升可能只有 20% 到 40%，但在副作用容易隔离、可回滚的任务里，收益可能接近“无限”；数学和代码之所以适合 agent，正是因为验证、git 和人工审查提供了护栏。相比之下，许多知识工作缺少同等的可逆性和追踪能力。正如他所说：“最重要的问题是，你可以把哪些决定交给 agent 信任？”

他还提醒，行业已经很快出现 benchmark fatigue，模型发布的分数不等于真实可用性。与其被 FOMO 驱动全面部署，不如理解技术边界，在可控风险的决策上逐步扩大 agent 的权限。
