The Takeaway：AI 时代真正稀缺的基础设施，不是单独的 GPU，而是让数据、模型、agent 和权限以足够快、安全且可恢复的方式协同工作的 software infrastructure。

Renen Hallak，VAST Data founder and CEO，把 AI stack 描述成从 energy、chips、infrastructure、models 到 applications 的五层结构，并认为中间的软件层正在成为新一代 operating system。所谓 AI factory 不只是堆 GPU，还需要更高的 power density、更快的网络、更大的 SSD，以及让图片、视频、声音和自然语言数据持续喂给训练与 inference 的系统。随着企业把经验沉淀为 fine-tuned models 和 weights，model management、confidential computing 以及不暴露企业数据和模型 weights 的信任边界会越来越重要。
