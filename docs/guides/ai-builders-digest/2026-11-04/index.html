Latent Space：Building Legal Agents When You Can't See the Data - Jacob Lauritzen, CTO of Legora

核心观点： 法律 agent 的长期护城河不只是接入更强模型，而是把领域工作流、隐私约束、评测体系和任务编排一起产品化。

Legora CTO Jacob Lauritzen 介绍了从法律检索 agent 发展出的完整工作台：agent 可以起草和编辑文件，Tabular Review 能对大量合同批量提取信息，Lists、Intake 和 Portal 则负责把律师、客户与 agent 的工作串起来。核心产品判断是，领域公司应该替用户在模型、成本、延迟、治理和区域可用性之间做路由，而不是把所有模型选择都交给律师。

在数据不能直接查看的法律场景，Legora 用工程师、律师和 legal engineer 共同做评测，把尽调报告、风险发现等任务拆开衡量；模型发布也可能在某些任务上进步、在另一些任务上退步。Lauritzen 认为，当前约 60% 的法律工作已经能做得很好，接下来更多是成本、延迟和更复杂任务的竞争。他还强调，产品最终会从“启动一个 agent”走向一个让人审查、协作和改进 agent 运行结果的 command center。正如他说的：“We're a hundred engineers now, and it feels like we're way too small.”
