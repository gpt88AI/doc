Latent Space：[One Million AI Engineer Special] How Stanford Teaches AI-Native Engineering — Mihail Eric, Monaco

一句话结论： Stanford 的 AI-native engineering 课程把重点从“到处试用 coding agent”推进到 context engineering、架构设计和真实开源贡献，目标是让有基础的工程师在复杂代码库中可靠地放大产出。

Mihail Eric 同时是 Stanford CS 146S《Modern Software Developer》教师和 Monaco 的 Head of AI。他回顾课程从 2024 年构思、2025 年首次开课到今年重做：早期课程更像横跨整个 SDLC 的工具巡礼，如今则更强调为 agent 提供精确上下文、先处理设计与架构、再把复杂实现交给模型。课程面向已经掌握传统计算机科学基础、准备进入生产环境的学生，而不是替代基础训练。

今年课程把作业改成参与真实 AI-native 开源项目。学生需要在大型代码库中工作，由维护者 review 代码并帮助建立软件系统的 mental model；课程也提供额外工具额度，让学生观察 agent 在更高 token 预算下能做到什么。Eric 的判断是：AI-native engineer 仍然很有价值，但必须同时具备软件工程基本功、系统权衡能力和驾驭 agent 的能力。
